# Bundled fonts

Downloaded 2026-11-02 from the official Google Fonts repository, unchanged.

- Jua Regular, Woowahan Brothers: https://github.com/google/fonts/tree/main/ofl/jua . `Jua-Regular.ttf`, `jua-OFL.txt`, and `jua-METADATA.pb`.
- Lilita One Regular, Juan Montoreano: https://github.com/google/fonts/tree/main/ofl/lilitaone . `LilitaOne-Regular.ttf`, `lilitaone-OFL.txt`, `lilitaone-FONTLOG.txt`, and `lilitaone-METADATA.pb`.

Both use SIL Open Font License 1.1. Original copyright and license texts are bundled beside the font binaries. No glyphs, outlines, names, or font metadata were modified. `manifest.json` records original download URLs, sizes, and SHA-256 checksums. Runtime fonts load from the app bundle, without a Google Fonts network request.
