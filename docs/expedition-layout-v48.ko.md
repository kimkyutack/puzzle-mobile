# 동물 구출 원정: 일반전 화면 통일

원정의 별도 파란 배경, 전용 헤더, 열린 길/이동 요약, 상단 X 버튼, 화면 하단의 별도 보상 영역을 제거했다. 일반전과 같은 `game-shell playing`, `ArtSurface scene="play"`, `PlayHud`, `board-area`, `level-ribbon`, `play-footer` 구조와 이미지 자산을 사용한다.

일반전 레벨판 위치에 `동물 구출 원정 3`처럼 코스 번호를 표시한다. 긴 이벤트 이름을 담기 위해 동일한 레벨판 이미지를 200px로 표시한다. 원정의 하트/보유 도구 미소모 규칙은 유지하며 도구 슬롯은 비활성화한다. 하단 설정에서 계속 플레이하거나 진행을 보관하고 원정 메뉴로 나갈 수 있다. 설정을 열면 보드 입력을 차단한다.

승리/실패는 일반전처럼 기존 퍼즐 위의 모달로 표시한다. 승리 포스터와 선물 이름·수량을 함께 표시하며 기존 서버 검증/보상 수령 계약은 유지한다.

## 검증

- TypeScript 및 웹 프로덕션 빌드 통과, `git diff --check` 통과.
- 실제 컴포넌트 + 격리된 합성 API: 320×658, 390×844, 540×900 CSS px. 한국어 및 540px 영문 레벨판 넘침 없음.
- 설정 열기/계속 플레이/나가기/재개, 5코스 승리 모달과 코인 150·별빛 대폭탄 1·토끼 1 수령 내역 확인.
- 본편 `PlayHud`와 원정 `PlayHud`를 같은 상태/390px 폭으로 캡처하여 같은 비교 입력에서 확인했다. 같은 프레임, 목표/캐릭터/이동 위치, 글꼴을 사용한다.
- 원정 화면 폭이 각 뷰포트와 일치하고 이미지 누락 없음. 증거: `output/verification/expedition-header-v48/`.
- 보드 종료 시 PixiJS 텍스처 바인딩 해제 경고가 관찰됐다. 설정/재개/보상 수령 동작과 이미지 표시는 정상이며 렌더러 자원 해제 개선은 이 변경 범위에 포함하지 않는다.

운영 배포, 네이티브 동기화, 아카이브 및 실기기 검증은 실행하지 않았다.
