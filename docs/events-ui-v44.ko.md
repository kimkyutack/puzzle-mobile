# 이벤트 화면 및 축제 입장 개선

2026-11-09.

## 화면

- 신규 이벤트 배너의 얇은 CSS 외곽선과 연결된 탭 바를 없앴다. 새 꽃 장식 프레임과 기존 게임 버튼 이미지를 사용한다.
- 배너는 기존처럼 한 칸을 유지한다. 390px 화면에서 전체 높이는 211px로, 이벤트 수에 따라 세로로 누적되지 않는다.
- 축제 모달은 큰 정원 장면, 장면 안의 복원 장소 아이콘, 리본 제목, 두루마리 목표판, 주요 행동 버튼으로 구성한다.
- 직접 제작한 꽃 프레임과 두루마리를 아홉 조각으로 나누어 표시해 모서리와 말린 부분이 늘어나지 않게 한다.
- ‘무료 참여’, ‘무료로 축제 시작’ 문구와 별도의 시작 단계를 제거했다. 입장 시 서버에 참여를 등록하고 초대장 이야기로 이어진다. 기존 참여자는 바로 자신의 복원 상태를 본다.
- 복원 완료 후 기존 장면에 장식이 나타나는 처리와 영구 장식 보상 규칙은 유지한다.

## 입장 및 연결

- 운영 서버의 공개 기능 목록에 `flowerlight`, `animalExpedition`이 없고, 배포 이력도 신규 이벤트 구현 이전이었다. 검증된 신규 이벤트 API를 운영 Worker에 반영했다.
- 입장 및 복원 요청은 20초 뒤 연결 오류로 돌아오며 재시도할 수 있다. 모달 안의 주 행동 위치에 상태와 오류를 표시한다.
- 응답에 해당 사용자와 축제 참여 정보가 있는지 확인한 후 이야기를 연다. 성공 HTTP 코드만으로 참여했다고 표시하지 않는다.
- 일시적인 실패 후 같은 요청 식별자로 다시 시도한다. 서버의 기존 참여 유지 및 중복 보상 방지 처리를 사용한다.
- 계정 변경 시 모달 인스턴스를 분리하고, 닫힌 모달의 응답으로 UI를 다시 갱신하지 않는다.

## 검증 및 운영 반영

- 웹 빌드와 타입 검사 성공.
- 연결 제한/재시도, 번역, 이벤트 관련 테스트: 3개 파일 / 18개 통과.
- 서버 이벤트, 초반 밸런스, 기존 엔진 규칙, 운영 콘솔 관련 테스트: 4개 파일 / 36개 통과. 위 테스트 집합과 이벤트 테스트 파일이 중복되므로 합산하지 않는다.
- 격리된 브라우저 화면에서 입장 → 이야기 → 목표판, 복원 후 입구 추가, 이벤트 탭 전환을 확인했다.
- 서버 미지원 응답, 참여 정보가 없는 응답, 지연 응답 후 재연결을 확인했다.
- 320px 영문 화면에서 두 자리 목표 수치, 390px 기본 화면, 540px 완료 화면을 확인했다. 페이지/모달 가로 넘침과 누락된 이미지가 없었다.
- 화면 검수 데이터는 합성 데이터다. 운영 사용자 계정으로 실제 참여/보상 지급을 실행하거나 실기기에서 확인하지 않았다.

운영 Worker: `puzzle-mobile`, 버전 `2c161055-3069-4199-8580-c11b450893ed`.

배포 전 패키징 검증과 마이그레이션 목록 조회를 수행했다. 미적용 DB 마이그레이션은 없었다. `--keep-vars --strict`로 기존 운영 변수/비밀값을 유지하며 배포했다. 배포 후 공개 운영 설정의 두 이벤트가 모두 활성화되었고 `/api/health`가 정상임을 확인했다. 기존 엔진 호환 버전은 유지했다.

이번 작업에서 네이티브 동기화, iOS 아카이브, Git 커밋/푸시는 실행하지 않았다. 새 화면을 앱에 포함하려면 프로젝트의 `npm run native:release`를 실행한다.

검증 화면, 로그, 공개 서버 확인 결과는 `output/verification/event-layout-v44/`에 저장했다.
