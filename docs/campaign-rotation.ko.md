# 구름정원 캠페인 규칙 편성

공개 캠페인은 20,000레벨이다. 이 변경은 레벨 41–44, 55–57, 67–69와 101–400 구간의 일반 퍼즐 270판을 교체한다. 10레벨마다 나오는 물길·동물 길 안내 판은 기존 흐름을 따른다. 현재 퍼즐 엔진 1.11.0에서 새로 시작하는 판부터 적용된다.

| 첫 레벨 | 도입하는 플레이 | 연습 후 나오는 조합 |
| --- | --- | --- |
| 101 | 자석 레일 양 끝 공략 | 상자로 가려진 레일, 갈라진 서리 구역, 색상 화분과 덩굴 |
| 201 | 물관을 열고 씨앗을 출구까지 배달 | 출구 두 곳이 분리된 보드, 자석 너머 씨앗, 번지는 이끼 |
| 301 | 매 수 위치가 바뀌는 화분을 따라가기 | 움직이는 화분과 자석을 함께 공략, 화분을 따라가며 양쪽 서리 제거 |

각 구간 첫 세 판은 도입과 연습으로 구성한다. 이후 일반 퍼즐 2~3판마다 공략 방식이 바뀐다. 어려운 판에서는 분리된 목표, 여러 방향에서 열어야 하는 통로, 특수 타일 발동 목표를 사용한다. 가능한 경우 시작 로켓이나 폭탄이 실제 목표 여러 곳에 닿는 위치를 안내한다. 이동 횟수는 기존 공개판의 수치를 하한으로 사용한다.

## 401–20,000레벨

401레벨부터 20,000레벨까지 196개 구간의 일반 퍼즐 17,640판을 개편한다. 각 구간 첫 세 판에는 장치 또는 장치 순서를 익히는 판이 나오고, 이후 2~3판마다 현재 장치, 두 장치를 차례로 작동시키는 판, 이전 장치를 복습하는 판이 돌아온다. 10레벨마다 나오는 이야기 퍼즐 1,960판을 유지한다.

새 엔진 1.12.0이 지원하는 장치 동작은 14종이다. 연결·분기·교대·동시·연속 스위치, 컨베이어, 색상 충전기와 릴레이, 연쇄·낙하 감지기, 합성·로켓·꽃폭탄·공중 특수 타일 장치를 사용한다. 두 동작의 순서를 구간마다 바꿔 총 196개 조합을 편성한다. 맵은 자석, 상자, 씨앗 배달, 움직이는 화분 등 기존 장애물과 장치를 섞는다. 현재 구역, 컨베이어 이동 방향, 작동 조건과 진행은 인게임에서 확인할 수 있다.

1.11.0 앱은 기존 카탈로그를 받는다. 개편에 들어가는 보드의 기존 이동 횟수는 하한으로 유지한다. 앱과 Worker가 모두 1.12.0을 지원하면 개편 보드를 받을 수 있다. 플레이 중이던 판은 그 판에 저장된 보드와 엔진으로 이어진다.

### 직접 부수는 장애물

장치 퍼즐 사이에 직접 파괴 퍼즐을 세 판씩 편성한다. 404레벨 항아리, 504레벨 토끼 석상, 604레벨 보관 상자, 704레벨 수정이 각각 첫 소개다. 20,000레벨까지 10가지 패턴을 1,776판에 배치한다. 항아리 밑 서리, 석상 옆 자석, 씨앗 출구를 막는 항아리처럼 기존 장애물과 섞인 판도 포함한다.

- 항아리와 석상은 옆에서 아무 색이나 맞추거나 특수 타일을 직접 맞혀 부순다. 석상 전용 판에는 한 칸짜리 독립 석상 10개가 등장하며 각각 6번 맞아야 부서진다. 한 줄의 로켓은 범위 안에 있는 석상을 각각 한 번씩 타격한다. 혼합 판의 2×2 석상은 한 폭발에 여러 칸이 맞아도 한 번만 피해를 받는다.
- 항아리 전용 판에는 3~5번 맞아야 하는 항아리 10~12개, 수정 전용 판에는 특수 타일로 깨는 수정 10개가 나온다. 보관 상자 전용 판에도 10개를 배치한다. 판에 따라 두 줄, 양쪽으로 갈린 덩어리, 가운데 일곱 칸을 잇는 줄을 사용한다.
- 보관 상자에는 내용물 아이콘을 표시한다. 상자가 부서지면 같은 칸에 항아리 또는 수정이 나타난다. 목표는 내용물까지 부순 뒤 줄어든다.
- 수정은 로켓, 꽃폭탄, 글라이더, 꿀벌집이나 보유 도구의 직접 타격으로 부순다. 다단계 장애물에는 남은 타격 횟수와 균열이 간 이미지를 표시한다.
- 스프라이트는 내장 ImageGen으로 제작했다. [원본과 게임용 WebP](../packages/assets/breakable-obstacles)는 동일한 구도의 투명 2×2 시트에서 분리했다. 원본 프롬프트는 작은 보드에서도 실루엣이 읽히는 정면에 가까운 3D 게임 아이콘과 동일 외형에 균열을 더한 짝을 요청했다.

100판마다 한 규칙을 도입한다는 목표라면 1레벨부터 19,901레벨까지 총 200개의 도입 지점이 생긴다. 새 규칙은 플레이어가 성공시키기 위해 하는 행동이나 판단이 달라야 한다. 보드 좌우 반전, 색 바꾸기, 장애물 내구도 변경, 기존 규칙의 조합은 각각 변형과 복습용으로 센다.

### 1,801–2,400레벨 공방 퍼즐

엔진 1.14.0에서는 1,801레벨부터 100판마다 짝빛 받침대, 쌍둥이 통로, 정원 염색틀, 꽃잎 저울, 거울 화단, 바람 우물이 차례로 열린다. 처음 3판에서 새 동작을 연습하고, 상자나 서리와 섞인 판과 직전 규칙의 복습판에서도 다시 만난다. 이 구간의 120판을 교체하고 이야기 퍼즐과 직접 파괴 퍼즐의 배치를 유지한다. 기존 이동 횟수는 그대로 하한으로 사용한다.

공방의 보드 구성 54종은 각각 기본 배치와 두 가지 무작위 배치에서 시작 아이템 없이 풀리는지 검사한다. 검증 명령은 `node --import tsx tools/level-validation/workshop-build.ts --verify`다.

새 동작이 필요한 규칙은 엔진과 보드 표시를 함께 추가한다. 서버와 앱에서 같은 액션을 재생해 같은 결과가 나오는지 확인하고, 해당 규칙을 지원하는 클라이언트에만 그 보드를 제공한다. 출시 후에는 레벨별 첫 시도 클리어율과 재시도, 남은 이동 횟수, 시작 도구를 선택한 판의 결과를 함께 본다. 자동 플레이로는 검사 대상 초기 배치의 해결 경로를 확인하고, 실제 체감 난이도는 플레이테스트로 확인한다.

## 검증

```sh
node --import tsx tools/level-validation/rotation-build.ts --verify
node --import tsx tools/level-validation/long-campaign-build.ts --verify
node --import tsx tools/level-validation/breakable-build.ts --verify
npm test -- tests/campaign-rotation.test.ts tests/long-campaign.test.ts
```

검증은 400레벨까지의 보드 구성 93개, 후반 장치 보드 434개, 직접 파괴 보드 60개에 대해 엔진 구조, 시작 시 유효한 교환, 시작 도구를 선택하지 않은 자동 클리어 경로, 서로 다른 두 초기 배치를 확인한다.
