# 정원 산책과 여러 개 꾸미기 · v22

2026-11-04. 실제 홈의 `HomeGardenWorld`와 공통 `WorldMap`에 연결했다.

## 동물과 방문객

- 배치한 꽃귀 토끼·치즈 고양이·웰시코기가 열린 땅을 천천히 산책한다. 네 방향 인접 칸으로 길을 찾고 건물·시설의 전체 점유 칸과 잠긴 구역을 피한다. 동물은 배치한 집 위치에서 7칸 이내를 돌아다닌다.
- 동물은 걷기 → 잠시 멈추기 → 하품 → 10~19초 수면 → 기지개를 반복한다. 각 개체의 시작 시각과 경로가 달라 동시에 같은 동작만 반복하지 않는다. 일반 방문객은 걷다가 주변을 보거나 정원을 감상하고 기지개를 켠다.
- 사람 방문객 2종은 구매하지 않아도 등장한다. 열린 면적을 72칸으로 나눈 값을 올림해 최대 10명으로 제한한다. 현재 하늘 정원만 열면 2명, 온실 작업실까지 4명, 분수 테라스까지 5명이다. 걷을 공간이 없으면 수를 줄인다.
- 산책 좌표와 모션은 앱의 로컬 표현이다. 서버 요청을 보내지 않고 원래 배치·소유·재화·퍼즐 상태를 바꾸지 않는다. 선택/이동/보관에는 저장된 원래 배치 위치를 사용한다. 꾸미기 중과 연출 줄이기 설정에서는 움직임을 멈춘다. 보관한 동물은 산책에서도 사라진다.
- 캐릭터와 건물을 발 위치의 깊이에 따라 함께 그려 건물 앞뒤 관계를 유지한다. 바닥은 캐시에 보관하고 움직이는 화면만 최대 30fps로 갱신한다. 숨겨진 탭에서는 시뮬레이션을 진행하지 않는다.

## 구매와 연속 설치

1. 꾸미기 상점에서 ± 버튼 또는 직접 입력으로 수량을 1~100개 선택한다. 2026-11-05 산책로에만 있던 +10 단축키는 제거했다.
2. 상품 이미지·수량·총 코인 가격을 확인하고 구매한다. 한 번 차감하고 각 사본에 고유 ID를 지급한다. 구매를 취소하면 차감하지 않는다.
3. 산책로, 또는 여러 개 보관한 일반 장식을 고르면 연속 배치로 진입한다. 손가락을 끌면 지나간 칸에 바로 미리보기가 놓인다. 빠른 드래그도 칸 사이를 보간한다. 물건 크기를 포함한 점유, 잠긴 땅, 이미 깔린 칸은 건너뛴다.
4. 한 칸 취소, 지도 이동, 전체 취소를 지원한다. 두 손가락 확대/이동도 유지한다. 설치 버튼으로 최대 100개를 한 요청·한 리비전으로 저장한다. 취소하거나 남은 사본은 보관함에 유지한다.

동물은 개별 배치를 유지한다. 다른 물건을 이동/회전/보관하는 기존 흐름도 유지한다.

2026-11-05 상점 카드 보정: 산책로 전용 +10 버튼과 해당 스타일을 제거했다. 가로형 카드 원화의 모서리를 자르던 잘못된 분할값 대신 원본의 상단 80·좌우 112·하단 88px 분할을 사용하고 같은 배율로 테두리를 표시한다. 실제 홈과 체험 정원 상점에 같은 기준을 적용한다. 장식 이미지는 고정 높이의 독립 영역에 비율을 보존해 담으며 카드 내용 때문에 이미지 높이가 눌리지 않게 했다. 실제 HomeGardenWorld의 격리 화면 390×844와 320×740에서 카드 정렬·수평 넘침 없음·+10 없음·11개 220코인 및 100개 2,000코인·구매 확인 진입을 확인했다. 타입 검사 통과. 검수 자료는 `output/verification/garden-shop-cards-v28/`에 있으며 실제 계정/API 구매는 하지 않았다. 이번 화면 수정은 이후 앱 재빌드가 필요하다.

`POST /garden/shop/buy`는 선택적 `quantity`(기본 1)를 받고 `instanceIds`, `quantity`, 총액 `cost`를 반환한다. 이전 단일 구매 요청과 `instanceId` 응답도 호환한다. 가격은 서버 카탈로그를 사용하고 총 보유 1000개 한도를 검사한다. 같은 키 재시도는 재차감하지 않고 다른 수량으로 키를 재사용하면 거절한다.

`POST /garden/world/commands`의 새 `type:paint`는 `expectedRevision`, `placements`, `key`를 받는다. `applyGardenPlacementBatch`가 모든 소유권·좌표·회전·풋프린트·점유를 순서대로 검사한 뒤 원자적으로 저장한다. 한 개라도 유효하지 않으면 부분 설치하지 않는다. 리비전 충돌 시 미리보기를 비우고 정원을 새로 불러온다. 새 DB 스키마는 필요하지 않다.

## 이미지

built-in `image_gen`으로 3×2 자세 시트 5장을 새로 제작했다. 동물은 기존 원화를 참조해 정체성을 유지했다. 원본 PNG는 `packages/garden-world/art/source/residents-v22/`에 보존했다. 정확한 프롬프트·참조·생성 경로는 `packages/garden-world/art/residents-v22-prompts.json`에 있다. `tools/garden-world/build-residents.ts`는 원본을 수정하지 않고 30개 프레임을 잘라 같은 비율·발 기준선으로 정규화한다. 런타임은 `packages/garden-world/art/runtime/residents-v22/`의 PNG를 사용한다. CSS/코드로 사람이나 동물을 그리지 않는다.

## 검증과 적용 상태

- 정원 모듈 5파일·42검사 통과. 빠른 드래그 보간, 수량 소진, 장식 풋프린트, 원자성, 중복 키, 소유권, 리비전, 길찾기, 동물 모션 순환, 이동/보관을 검사했다.
- 실제 Worker HTTP + 격리 D1의 16개 흐름 통과. 10개/100개 구매, 단일 차감·재시도, 96자 키, 잔액 부족, 일괄 배치 재조회, 겹침 시 전체 롤백 포함. 실제 사용자의 계정·DB에는 테스트 구매를 하지 않았다.
- CUA의 실제 홈 화면에서 390×844/320×740 검수. 10개 구매 후 실제 드래그로 6칸 설치, 보관함 4개 유지, 새로고침 복원, 동물 3종 구매·배치와 산책/수면, 방문객 이동을 관찰했다. 수량 입력의 수평 넘침과 관찰한 콘솔 오류는 없었다.
- `npm run typecheck`, `npm run native:release` 통과. JS/CSS와 30개 새 이미지가 web/iOS/Android에서 SHA-256으로 일치한다. APK/IPA 빌드·설치는 수행하지 않았다.
- 증거는 `output/verification/garden-life-v22/`에 있다.
