## 기능

- 기존 실제 꽃잎/5단계/장식/코인/도구 보상을 그대로 사용한다. 시안의 예시10/20/30 수치로 게임 규칙을 변경하지 않았다. 다음3단계 보상을 표시하고 마지막 구간에는 직전 수령 상태도 함께 표시한다.
- 코인은 기존 `Icon id=coin`, 도구와 장식은 기존 게임 원화 사용.
- 퍼즐 플레이 → 기존 레벨 시작 경로, 단계1 복원 → 다음 보상 카드 갱신 및 설치 안내 확인.
- 단계2 복원 → 대화2문장 넘기기 → 보상 목록 복귀/수령 체크 확인.
- 첫 참여 등록과0/20 표시 확인. 첫 참여 대화 표시 자체는 이 검수에서 입증하지 않았다.
-5단계 완료 영문 화면/수령 체크/내 정원 버튼 확인. 진행도에 남았던 한국어를 동적 번역 문구로 수정하고 영문 표시를 확인했다. 일본어 항목도 추가했다.
- 동작은 isolated synthetic fixture로 확인했다. 운영 장식 지급/DB 저장을 검증한 것이 아니다.
