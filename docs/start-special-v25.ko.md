# 플레이 시작 호환과 특수 아이템 연출 · v25

2026-11-05.

## 시작 오류

운영 `/health`의 엔진은 1.2.0이고 앱 소스의 최신 엔진은 1.3.0이었다. 앱이 무조건 1.3.0으로 `/runs/start`를 요청해 서버의 버전 검증에서 `INVALID_INPUT`을 받았다. 별도 캠페인 코드 전체를 운영에 덮어쓰지 않고 앱의 시작 방식을 고쳤다.

`run-gateway.ts`가 앱 세션당 한 번 서버 엔진을 확인하고 시작 요청과 `StartLevelModal`의 목표 미리보기에 같은 버전을 사용한다. 상태 확인은 리소스 로딩과 병렬로 수행하며 타일 교환·폭발 중 추가 통신은 없다. 앱을 켜 둔 사이 배포 버전이 바뀌면 버전 관련 거절에 한해 상태를 새로 확인하고 동일 요청 키·부스터로 한 번 재시도한다. 네트워크/하트 오류에는 자동 재구매·중복 시작을 하지 않는다. 알 수 없는 미래 버전은 업데이트 안내로 차단한다.

상태/시작 HTTP는 20초 제한을 두고 실패 시 로딩 상태를 해제한다. 재시도에도 기존 요청 키를 유지해 응답 유실로 이중 차감하지 않는다. 시작 오류는 일시 알림과 버튼 위 안내에 표시한다.

운영에서 새 임시 게스트 하나로 기존 1.3.0 요청의 오류를 직접 재현했다. 정상 승인 경로로 1~19판을 클리어한 뒤 수정된 게이트웨이로 20판을 시작했고 목표 미리보기 일치·동일 키 재요청·하트 5개 보존을 확인했다. 전체 시작에 `/health`는 한 번이었다. 검증 계정은 정리했다. 기존 사용자 계정·설치 토큰·운영 DB 직접 수정은 사용하지 않았다. 증거는 `output/verification/special-v25/production-start.json`이다.

## 이미지

built-in `image_gen.imagegen`으로 새 가로·세로 폭탄과 기존 무지개등의 충전 원화를 제작했다. 가로 폭탄은 좌우로 긴 청색 몸통·금색 고리·산호색 양끝, 세로 폭탄은 상하로 긴 별도 원화다. 실제 타일 크기에서 너무 가늘었던 첫 시안은 보존하고 더 두꺼운 형태로 수정했다. 기존 원작 게임 그림을 추출하지 않았다.

- 최종 원화: `packages/assets/source/wind_row_v25.png`, `wind_column_v25.png`, `rainbow_charge_v25.png`.
- 첫 시안: `packages/assets/drafts/special-v25/`.
- 정확한 프롬프트·참조·생성/저장 경로: `packages/assets/special-v25-prompts.json` 및 `special-v25-refinements.json`.
- 재생성/검사: `npm run assets`. 현재 209개 매니페스트 항목·3개 아틀라스·17개 시퀀스, 누락 0.

`wind-column`을 가로 원화의 90도 회전으로 대신하던 매핑을 제거했다. 보드·조합·비행기 운반·발견 창에 실제 세로 원화를 사용한다. 선형 폭탄은 발사 중에도 진행 축을 유지한다. 게임 규칙과 효과 범위는 바꾸지 않았다.

## 무지개등

기존 정원 등불의 외형을 유지한 채 전경에서 약 2.15배 확대하고 떠오른다. 900ms 충전 후 대상 타일에 컬러 광선·흰 중심광·빛 입자·대상 표식을 연결하고 650ms 이동이 끝나는 1550ms에 파괴와 충격음을 맞춘다. 등불은 타격까지 유지하고 이후 사라진다. 모서리에 있으면 확대된 그림이 보드 안쪽에 머물도록 중심을 조정한다. 두 아이템 조합에는 기존 520ms 합성 단계가 앞선다.

다음 연쇄에서 깨질 타일이 충전 중 먼저 사라지는 것도 수정했다. 중간 낙하를 따라 기존 타일 ID의 제거 시점을 추적하므로, 타일의 최초 위치에 제거 이벤트가 없더라도 즉시 지우지 않는다. 기존의 최종 보드 재정렬 방식과 로컬 게임 결과는 유지한다. 파티클은 180개 상한을 유지하며 `연출 줄이기`는 110ms 간단 피드백을 사용한다.

## 검증과 적용 범위

- 시작 협상·재시도·시간 제한·모션·합성·충전/연쇄 타이밍·타일 이동 관련 6파일 26검사 통과. 이미지/보드 경계/장애물 관련 3파일 11검사 통과.
- 배포된 v24 엔진 소스와 현재 로컬 엔진으로 이전 200판·1,429행동을 각각 재생해 모든 초기 상태·행동 수락·이벤트·상태 해시가 일치했다. `engine-compat.json`.
- 운영 서버와 같은 1.2.0 코드를 임시 D1에 띄워 실제 앱에서 20판 목표 확인→플레이→보드 진입을 390px에서 확인했다. 별도 무통신 9칸 보드에서 가로/세로 활성화, 무지개등 확대·광선·타일 보존·정렬 후 입력 해제, 320px 모서리 확대와 110ms 축소 연출을 검수했다. 수평 넘침은 없었다. 격리 검수 페이지의 초기 급수구 설정 오류는 수정한 뒤 재검수했다.
- `npm run native:release` 성공. 웹 배포 빌드와 iOS/Android 리소스 복사를 완료했다. 동기화 해시는 `native-sync.json`, 실제 캡처는 `output/verification/special-v25/`에 있다. `rainbow-v25.gif`는 실제 브라우저 캡처를 이어 붙인 증거다.

이번 수정에는 Worker 배포나 DB 변경이 필요하지 않다. 운영 엔진은 1.2.0을 유지한다. 새 이미지와 클라이언트 수정은 앱을 다시 빌드·설치해야 적용된다. APK/IPA 배포 또는 TestFlight 업로드는 수행하지 않았다. 별도 1.3.0 캠페인 API의 운영 공개는 이 작업에 포함하지 않았다.
