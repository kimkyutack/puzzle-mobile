## 발견과 수정 이력

1. **P1 — 대상마다 비율이 어긋남.** 타일 점유 폭만으로 그림을 늘려 온실·특히 가로등이 크고, 동물이 사람만큼 컸다. `art-scale.ts`에서 표시 크기를 점유 영역과 분리했다. 해당 계산은 실제 그리기·미리보기·알파 선택에 공통 적용하며 동물은 이동/편집/미리보기에 같은 `residentArtBounds()`를 사용한다.
2. **P2 — 잔디와 길의 재질이 다름.** 거친 무늬와 불규칙 판석 대신 미세한 황록색 잔디와 작은 크림색 사각 포장석을 새 래스터로 제작했다. 잔디 경계가48×24px에서 사라지는 것을 확인해 보강했고,64×32px 재비교에서는 선이 너무 강해 다시 대비를 절반으로 낮췄다. 마지막 생성의 녹색 고주파 대비는 하위1% 약−4로 참조 수준에 가깝다.
3. **P2 — 타일 간격도 달랐음.** 원본 잔디의 대각선 경계 간격은 약62px, 기존 변경 중 렌더는48px였다. 정원 렌더를 표준128×64 격자로 통일하고 홈 배율.5에서64×32px로 보이게 했다. 오브젝트 그림은 별도 채움 비율을 사용해 함께 커지지 않도록 했다. 320px에서는 첫 홈 배율이 화면 폭에 맞춰 줄어든다.
4. **P2 — 장식의 조형 차이.** 금색 덩굴 가로등을 작은 노란 랜턴/짙은 기둥/밝은 돌 발판으로, 석재 링 나무를 자연스러운 뿌리의 나무로, 두꺼운 금장 울타리를 꽃이 조금 달린 흰 말뚝 울타리로 교체했다. 정면/후면 별도 래스터와 공통 앵커를 사용한다. 새 울타리에는 기존 투영 보정을 중복 적용하지 않고 실제 발끝 중점(256,260)을 반영했다.
5. **P2 — 축소 시 빈 삼각형 노출.** 유한 지도 밖의 화면 모서리가 다른 색으로 보였다. 같은 생성 잔디 이미지를 CanvasPattern으로 반복해 지도 밖 배경까지 채우되 편집 시 소유 영역 구별과 실제 배치 가능 영역은 유지한다. 극단 축소에서도 수만 개 타일을 새로 그리지 않는다.
6. 최종 확대 비교에서 온실이 약6% 작고 사람은 투명 여백 때문에 실제 몸이 작게 보였다. 온실과 사람의 실제 실루엣 크기를 보정하고 다시 빌드·브라우저 검증·카탈로그 캡처를 수행했다. 현재 범위의 P0/P1/P2는 해결했다.
