# 초반 난이도 완화 · v41

사용자 확인 범위는 1~100레벨입니다. 그중 1~5레벨의 첫 튜토리얼은 유지하고 6~100레벨의 이동 횟수를 늘렸습니다. 101레벨 이후 구성과 퍼즐 규칙은 변경하지 않았습니다.

확인한 문제: 5레벨의 24회가 6레벨에서 12회로 급감합니다. 31~100레벨에는 이동 10회짜리 맵이 많고, 일부 고난도 고정판의 인증 경로 여유가 1~2회, 53레벨은 새 낙하 규칙에서 여유 0회였습니다. 실제 시작은 랜덤 배치이므로 고정판 최적 경로를 바탕으로 한 예산이 초보자에게는 빡빡했습니다.

## 조정

- 일반판 최소 20회, 쉬운 판 최소 22회.
- 어려움 최소 22회, 매우 어려움 최소 25회.
- 물길·동물 판 14회 → 22회.
- 기존 횟수에 난이도별로 3~6회를 더하는 방식과 최소 횟수를 함께 적용합니다. 이미 예산이 큰 판은 일반 30회·매우 어려움 32회에서 증가를 멈추며 기존 횟수를 줄이지 않습니다.
- 타일 색, 모양, 목표, 장애물, 층수, 씨앗, 서리, 물길 경로 및 클리어 보상은 유지합니다.

## 적용 방식

`publishedLevel`에서 서버가 내려주는 레벨 데이터에만 적용합니다. 엔진은 1.10.0을 유지합니다. 새 미리보기의 해시와 실제 시작 데이터에 같은 조정이 적용됩니다. 최신 앱의 레벨 다운로드 구조를 사용하므로 앱 재빌드·아카이브·스토어 업로드는 필요하지 않습니다.

진행 중인 판은 저장된 `Run.level`과 상태를 그대로 이어갑니다. 새로 시작·재도전하는 판부터 적용됩니다. 배포 전에 받아 둔 미리보기는 기존 `CONTENT_CHANGED` 재조회 흐름으로 갱신되며 도구는 차감하지 않습니다.

## 검증과 해석

- 실제 운영 데이터는 사용자·계정 식별자 없이 레벨별 결과 건수만 읽었습니다. 표본이 적고 중단에는 포기·실패 등 서로 다른 이유가 포함되므로 이를 실제 실패율로 취급하지 않았습니다.
- 대표 20개 레벨 × 동일 랜덤 seed 3개, 총 60개 판을 시작 아이템 없이 자동 탐색으로 비교했습니다. 탐색 성공은 53/60 → 57/60입니다. 봇은 모든 합법 이동의 결과를 계산하는 정책이며 이 수치는 사람의 승률·난이도 인증이 아닙니다.
- 새로 완화한 판에서 기존 63개의 인증된 초반 승리 경로를 재생했습니다. 튜토리얼 첫 이동, 전체 맵 유효성, 목표·지형·초기 RNG·보상 유지, 101 이후 동일성, 중복 조정 방지, 구버전 엔진 협상을 확인했습니다.
- 실제 분리 로컬 API에서 53레벨 미리보기 20회, 실제 시작 20회, 요청 재전송 판 1개를 확인했습니다.
- 실제 App에서 서버 레벨을 받아 시작한 53레벨의 이동 횟수 20회와 기존 목표 3개가 표시됨을 확인했습니다. 브라우저 경고·오류 없음.
