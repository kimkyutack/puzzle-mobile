# 이벤트 페이지 배치 정리

2026-11-09. 신규 이벤트 포스터가 세로로 누적되어 기존 활동이 화면 아래로 밀리는 문제를 수정했다.

- 도구 축제, 보물 카드, 출석 선물, 시즌 이벤트 바로가기를 페이지 맨 위에 배치했다.
- 꽃빛축제와 동물 구출 원정을 고정 높이의 배너 한 칸에 묶었다. 탭, 가로 스와이프, 키보드 방향키로 선택하며 자동으로 전환하지 않는다.
- 다른 탭에 받을 보상이 있어도 빨간점이 보인다. 해금되지 않았거나 운영 설정에서 꺼진 이벤트는 표시하지 않는다. 이벤트가 하나면 탭을 숨긴다.
- 기존 포스터 이미지를 재사용하고 상태와 입장 버튼을 배너 안에 배치했다.
- 좁은 화면의 영문 바로가기 이름이 줄바꿈되도록 조정했다.
- 시작 아이템 무제한 안내의 아이콘과 글이 겹치던 문제를 수정했다. 프레임이 삽입되는 DOM에서 순번 선택자 대신 명시적인 복사 영역 클래스를 사용한다.
