## 동작

- 위쪽 가운데의 화살표를 누르면 두 메뉴 행을 접거나 펼친다. 기존 아이보리 raster 캡슐과 화살표 이미지를 재사용했다. 그림은 작게 표시하되 실제 터치 영역은44×44px이다.
- `aria-expanded`와 `aria-controls`, 한·영·일 접근성 이름을 제공하고 Enter로도 동작한다. 숨긴 메뉴는 키보드/스크린리더 탐색에서도 제외된다.
- 접힌 상태를 `garden.home.extras-collapsed.v1` 로컬 설정에 저장한다. 저장할 수 없는 환경에서도 접기 기능은 동작한다.
- 두 행을 감싸는 요소는 펼친 상태에서 `display:contents`를 사용한다. 기존 행 높이·레이블·버튼 위치를 유지한다.

## 카메라 수정

기존 이동 제한은 전체 캔버스 높이를 기준으로 계산했다. 그래서 남쪽 가장자리가 메뉴 뒤에 남아 있어도 이동이 멈췄다. `constrainGardenCamera`에 선택적 가림 영역 인자를 추가하고, 홈에서 측정한 헤더/하단 메뉴 높이를 사용한다. 인자를 생략한 기존 호출은 전체 화면을 사용한다.

`HomeHub`가 헤더, 실제 메뉴, 화살표 위치와 화면 크기를 측정한다. 접기/펼치기·기기 크기 변경 시 측정값을 갱신한다. `WorldMap`은 드래그·휠·두 손가락·키보드·확대 버튼에 같은 제한을 적용한다. 보이는 영역의 중심이 바뀔 때 카메라 위치도 옮기며 확대 비율은 유지한다. 작은 정원은 보이는 영역 중앙에 놓고, 매우 작은 화면에서도 유한한 카메라 좌표를 유지한다.
