# 잠긴 타일 아래 계단 낙하 · v40

문제: 기존 열별 낙하는 잠긴 칸을 만나면 아래 구간의 보충을 중단했습니다. 아래 타일을 지워도 잠금 바로 밑에 빈칸이 쌓였습니다.

변경: 우선 기존 세로 낙하를 완료하고, 공급 입구와 연결된 주변 타일이 대각선으로 이동하여 잠긴 칸 아래를 채웁니다. 넓은 지붕 아래에는 마지막 짧은 옆 이동도 허용하여 가운데 빈칸까지 채웁니다. 옆 이동은 공급 경로에서 멀어지는 방향으로만 허용해 왕복을 막습니다. 각 우회 이동 뒤 세로 낙하와 보충을 다시 처리합니다.

잠금·장애물 자체는 이동하거나 통과하지 않습니다. 양쪽 모서리가 모두 막힌 대각선과 공급 입구까지 완전히 막힌 구간으로 타일을 생성하지 않습니다. 열린 물길에는 타일을 넣지 않습니다. 별도로 작성한 굽은 낙하 레인은 기존 경로를 따릅니다.

각 대각선·옆 이동을 `fall` 이벤트로 남겨 기존 렌더러가 꺾이는 실제 경로를 따라 움직입니다. 다른 열로 넘어간 신규 타일의 공급 순서 계산도 보정했습니다. 새 네트워크 요청을 추가하지 않았으며 게임 계산은 기존 로컬 엔진에서 수행합니다.

## 호환성

시뮬레이션 규칙 `1.10.0`부터 적용합니다. 이전 `1.0`~`1.9` 규칙과 진행 중인 저장 판은 기존 계산·재생 결과를 유지합니다. 새 앱이 서버와 새 규칙을 협상하여 시작한 판부터 적용됩니다. iOS/Android 아카이브는 수행하지 않습니다.

맵의 모양, 색 수, 장애물, 목표, 이동 횟수는 변경하지 않았습니다. 기존 인증 맵 110개를 그대로 새 규칙으로 재검증해 클리어 행동 기록을 `packages/content/src/gravity-flow-proofs.json`에 저장했습니다. 이전 인증 기록은 그대로 보존했습니다.
