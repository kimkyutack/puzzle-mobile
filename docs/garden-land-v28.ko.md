# 골드로 정원 20칸 확장 · v28

2026-11-05. 사용자 지정 가격은 **매번 1,000골드 고정**, 추가 면적은 **5×4, 정확히 20칸**이다. 기존 코인 지갑과 차감 순서를 사용하며 별·하트·장식 소유권·기존 배치를 초기화하지 않는다.

## 이용 방법

홈 → 정원 꾸미기 → 확장. 지도에 노란색으로 표시된 20칸을 확인하고 이전/다음 위치로 다른 자리를 선택한다. 코인 아이콘과 1,000 가격을 표시한다. 처음 누르면 구매 확인 단계로 이동하고, 여기서 확인해야 차감한다. 취소·위치 변경은 무료다.

구매 즉시 새 땅이 밝은 정원 바닥으로 바뀌며 면적이 20칸 증가한다. 확장한 땅을 계속 보여 주고 장식 놓기/계속 확장을 선택할 수 있다. 이어 구매한 장식의 최초 배치 위치도 새 땅을 우선한다. 잔액 부족 시 구매를 비활성화한다. 가격은 구매 횟수에 따라 오르지 않는다.

## 저장과 검증

정원 JSON에 선택적 `expansions` 배열을 저장한다. 기존 데이터에는 필드가 없어도 된다. 각 ID는 서버가 재계산하는 5×4 필지다. 단순히 클라이언트가 보낸 면적·가격·소유자를 신뢰하지 않는다. 기존 땅과 겹치거나 정원에 붙어 있지 않은 필지, 이야기 해금용 땅, 경계 밖의 필지를 거절한다. 지도 외곽은 새 필지에 맞춰 늘고 현재 확장 한도는 64×64 범위다.

`POST /garden/world/expand`는 인증 계정, 기존 리비전, 서버 가격을 검사하고 Player 차감·불변 원장·정원 저장·요청 영수증을 한 D1 배치로 확정한다. 같은 키/본문은 원래 결과를 돌려주고, 다른 본문 재사용·같은 땅 중복 구매·동시 리비전 충돌은 추가 차감하지 않는다. DB 스키마 마이그레이션은 필요 없다.

배치·연속 설치·방문용 스냅샷·산책 경로·방문객 수에 동일한 열린 땅 정의를 사용한다. 경로는 새 땅을 걸을 수 있고 방문객 수는 실제 중복 없는 열린 면적을 기준으로 계산한다. 이야기 시설의 원래 배치 구역 제한은 유지한다.
