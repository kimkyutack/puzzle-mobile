# 구역 맵 v37 검수

> 이전 검수 기록. 큰 그림 하나를 반복 타격하는 구성이 사용자 의도와 달라 v39에서 제거했다. 현재 디자인 검수는 `design-qa-progression-v39.md`를 따른다.

- 기존 학습 구간·스토리 스테이지를 보존하고 100레벨 이후 간단한 구역부터 도입한다.
- 104레벨: 차양 한 줄과 아래 상자. 204레벨: 차양과 굽은 물관. 404레벨: 두 차양과 2×2 저장함. 708레벨: 여러 장치와 층 상자를 배치한다.
- 실제 Board/CascadeBoard/PlayHud와 기존 PNG를 사용했다. 새 테마나 텍스트 기반 그림으로 대체하지 않았다.
- 각 판의 목표 수는 최대 4개이며 기존 헤더에 숫자와 아이콘이 표시되는 것을 확인했다.
- 실제 104레벨을 검증된 조작으로 5수 클리어하고 `won`, `idle`, 입력 잠금 해제를 확인했다. 새 검사 페이지의 React preamble 로딩 문제를 해당 HTML에서 수정했고 최종 검사 콘솔 오류는 없었다.
- Chrome 전체 페이지 캡처의 분할 합성 문제로 중간 이미지가 반복되어, 최종 204/404는 실제 화면 영역을 직접 캡처했다. 최종 비교 이미지는 `output/verification/progression-v37/progression-layouts.png`다.
- 110개 정의에 실제 엔진 승리 기록이 있으며 전체 테스트 477개를 통과했다. 실제 기기 FPS·사람의 성공률은 별도 검증 범위다.
