# 정원 사람·동물 네 방향 보행 · v26

2026-11-05. 사람의 위쪽 이동에 뒷모습이 없고, 동물의 위쪽 이동에는 정지한 장식 뒷면이 표시되던 문제를 수정했다. 정원의 이동 경로·방문객 수·동물의 저장된 집 위치·구매 및 재화 규칙은 바꾸지 않았다.

## 이동과 표시

- 등각 좌표의 `+X`는 오른쪽 아래, `+Y`는 왼쪽 아래, `-Y`는 오른쪽 위, `-X`는 왼쪽 위다. 사람과 동물이 같은 `residentHeading` 기준을 사용한다. 사람에게도 후방 시점을 적용하고, 후방 좌우 반전의 기준을 바로잡았다.
- `residentDirectionArt`가 앞·뒤 전용 보행 프레임과 좌우 반전을 선택한다. 위쪽으로 이동하는 동물도 정지 이미지 대신 다리가 움직이는 후방 프레임을 사용한다.
- 사람 2종, 토끼·고양이·강아지 3종의 앞 4장·뒤 4장, 총 40개 런타임 프레임을 연결했다. 두 대각선 원화에 각각 좌우 방향을 적용해 네 방향에서 보행한다. 사람은 뒤꿈치를 드는 통과 자세와 무릎이 앞으로 나오는 통과 자세를 구분한다.
- 프레임은 전역 시간 대신 실제 이동 거리로 진행한다. 멈춤·편집·연출 줄이기·백그라운드에서는 보행이 진행되지 않는다. 경로 중간 칸에서는 앞면 정지 자세가 번쩍 끼지 않고 같은 보행 주기를 이어간다. 경로가 끝나면 기존 대기 자세로 전환한다.
- 기존 하품·수면·기지개 프레임을 유지한다. 보행 때 임의의 상하 흔들림을 추가하지 않으며, 원화의 다리 동작을 사용한다.

## 원화

built-in `image_gen`으로 제작·편집했다. 기존 동물과 사람의 정체성·의상·색상을 참조했다. 모든 선택 원본은 변경 없이 보존한다. 프레임 추출·알파 잡티 정리·동일 배율·발 기준선 정렬만 기술적으로 처리하고 게임 그림을 코드로 그리지 않는다.

- 프롬프트·참조·생성 이력·선택 프레임: `packages/garden-world/art/residents-walk-v26-prompts.json`
- 보존 원본: `packages/garden-world/art/source/residents-walk-v26/`
- 적용 원화: `packages/garden-world/art/runtime/residents-walk-v26/`
- 빌더: `node --import tsx tools/garden-world/build-resident-walk.ts`
- 프레임 크기 256×256, 발 기준선 250, 동일 캐릭터의 여덟 프레임에 동일 배율을 적용한다. 40장 합계 2,733,969바이트다.

## 검증과 적용 범위

타입 검사, 정원 관련 3파일·17테스트, 격리된 웹 프로덕션 빌드가 통과했다. 기존 큰 JS 청크 경고는 남아 있다. 테스트는 사람/동물의 네 실제 이동 벡터와 앞·뒤 선택, 이동에 따른 4프레임 진행, 일시정지, 칸 도착과 경로 중간의 후방 유지, 기존 여가 자세, 배치 방향과 정원 경로를 확인한다.

브라우저의 390px 화면에서 다섯 종×네 방향을 확인하고 실제 WorldMap의 산책과 후방 보행 이미지를 관찰했다. 40장 모두 투명 모서리·256px 규격이고 격리 프로덕션 빌드에 포함된다. 프레임 비교표·GIF·화면·관찰 데이터·검사 로그는 `output/verification/residents-walk-v26/`에 있다. 검수 HTML/TSX는 `tools/garden-world/residents-walk-v26.*`이며 실제 계정·API를 사용하지 않는다.

이번 변경은 정원 클라이언트 소스와 원화다. 작업 중인 다른 기능의 번들을 덮어쓰지 않도록 별도 출력 폴더에만 검증 빌드를 만들었다. 네이티브 동기화·APK/IPA 설치·운영 배포는 하지 않았다. 설치된 앱에는 이후 앱 재빌드와 설치로 반영해야 한다.
