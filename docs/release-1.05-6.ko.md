# 1.05 (6) 준비 및 운영 배포

2026-11-06. 아카이브와 스토어 업로드는 하지 않았습니다.

## 화면 폭

- 공통 화면, 언어 선택, 구매 확인 레이어의 520px 최대 폭 제한을 제거했습니다. 556px 화면에서 발생하던 좌우 18px 여백을 재현하고 수정했습니다.
- 짧은 가로 화면의 390px 고정 화면 대신 실제 뷰포트를 사용합니다. 팝업 높이는 안전 영역을 제외한 화면 높이 안에 들어갑니다.
- 홈·상점·친구·길드·이벤트, 실제 퍼즐, 시작·설정·패스·순위·구매 확인 팝업, 언어 선택·로딩을 브라우저에서 확인했습니다. 퍼즐 타일의 별도 크기 제한은 유지합니다.
- 검증 너비: 320, 390, 556, 640, 768px 및 878×556 가로 화면. 실물 Z Fold8에서는 아직 확인하지 않았습니다.

## 렌더링 최적화

- 이미지 메타데이터 검색을 배열 전체 검색에서 ID별 Map 검색으로 변경했습니다.
- 이미지 테두리의 레이아웃 읽기를 모아서 실행하고, 표시 조건이 같으면 스타일 재설정을 건너뜁니다.
- 같은 120개 카드 비교에서 최초 스타일 설정은 240회→120회, 텍스트만 갱신했을 때는 120회→0회였습니다. 이 측정으로 실기기 FPS나 통신 지연 개선을 주장하지 않습니다.

## 검증 및 배포

- TypeScript 통과, Vitest 63개 파일 / 436개 테스트 통과, 운영 Worker dry-run 통과.
- 격리된 실제 Worker·임시 D1에서 구버전 협상, 미리보기 무변경, 콘텐츠 변경 거부, 기존 실행 복원, 일반·물길·동물 퍼즐의 로컬/서버 결과 일치를 확인했습니다.
- 운영 Worker `puzzle-mobile`의 활성 버전: `270a5748-2576-4114-9691-3b2486e9d6e7` (100%). 추가 적용할 DB 마이그레이션은 없었습니다.
- 배포 전 저장한 1.3.0 퍼즐이 배포 후 같은 상태로 복원되고 클리어됨을 확인했습니다. 최신 1.6.0으로 1~20레벨을 실제 API에서 클리어했으며, 시작·보상 확정 재시도, 하트 유지, 10회 클리어 보상, 축제 시작 재시도도 확인했습니다. QA 게스트 2개는 모두 정리했습니다.
- 위 검증은 모든 공개 레벨의 최신 규칙 난이도 인증을 뜻하지 않습니다.
