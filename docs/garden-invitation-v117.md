# 내 정원에 놀러 와!

승인한 하늘색 시안을 이벤트의 다섯 번째 탭 **정원 초대**로 구현한다. 기존 이벤트의 배경과 공통 푸터·모달은 유지한다. 청록색 배경을 사용하지 않는다.

## 진행

1. 레벨 5부터 초대 준비를 진행한다. 정원에 벤치 1개와 나무 1개를 배치하고 건물 1개를 복원한다. 이미 배치·복원한 항목도 인정한다. 서버가 실제 정원 소유물·배치·복원 기록을 확인한다.
2. 준비를 완료하면 길드 채팅에 **정원 방문** 버튼이 있는 초대장을 보낸다. 다른 사람의 정원이나 닉네임을 요청으로 지정할 수 없다. 재전송은 1분 간격이다. 길드가 없으면 길드 찾기로 안내한다.
3. 다른 사용자가 실제 정원 지도를 불러와 화면에 표시한 후 방문을 기록한다. 정원 미리보기 GET, 초대장 전송, 꾸미기, 본인 방문은 방문 수를 올리지 않는다. 같은 방문자는 한국 날짜 기준 하루 한 번 인정한다. 차단·삭제·아동 계정의 기존 교류 제한을 적용한다.
4. 방문 수와 보상은 기간 없이 누적한다. 재접속·주간 이벤트 교체로 초기화하지 않는다. 실제 방문 10명, 50명, 100명 순서로 선물을 받는다. 받을 선물이 있으면 이벤트 탭과 푸터에 알림을 반영한다.

| 방문 달성 | 보상 |
| --- | --- |
| 10명 | 코인 300, 망치 1 |
| 50명 | 코인 700, 무지개등 1 |
| 100명 | 코인 1,500, 꽃폭탄 2, 별빛 소원 정자 1 |

## 100명 전용 장식

**별빛 소원 정자** (`garden-starlight-wish-pavilion`): 3×3 건물, 상점 구매 불가. 황금 초승달·별 장식과 푸른 유리 돔, 내부 천체 모빌·소원 수반·좌석을 갖춘 전용 이미지다. 처음 수령할 때 보관함에 지급하며 자동 배치해 기존 정원을 덮어쓰지 않는다. 정원에 놓으면 전용 래스터 별빛이 천천히 반짝인다. 앞 건물의 실제 투명도에 따라 가려지고, 동작 줄이기 설정에서는 정지한다.

보상과 장식 지급은 동일한 D1 트랜잭션으로 처리한다. 동시 요청·재시도·서로 다른 요청 키로도 한 번만 지급한다. 장식 저장이 실패하면 코인·도구·수령 단계도 함께 취소한다.

## 연결

- `GET /garden/invite`: 준비 상태, 실제 방문 수, 수령 단계.
- `POST /garden/invite/prepare`: 서버 검증 후 준비 완료 저장.
- `POST /garden/invite/share`: 현재 길드 채팅에 정원 초대 카드 생성.
- `POST /garden/invite/visit`: 지도 표시 후 본인의 방문 기록. `(정원 주인, 방문자, 한국 날짜)` 중복 방지.
- `POST /garden/invite/claim`: 방문 목표·단계 검증 후 보상 지급.
- 기존 정원 방문 응답의 선택적 `invitationVisits` 표시가 있는 서버에서만 새 방문 기록 요청을 전송한다.
- `garden-v117` 아트 기능 표시를 사용한다. 구버전 클라이언트에는 같은 3×3 정자 이미지를 대체 응답하며, 서버 원본 장식은 변경하지 않는다.

## 검수와 반영 범위

원본 이미지와 생성 프롬프트는 `packages/assets/garden-invite-v117/source/`, `prompts.md`에 보관한다. 실행용 이미지와 한정 장식은 `runtime/`에 있다. 승인 시안의 텍스트와 화면을 하나의 이미지로 붙이지 않고, 별도 그림과 실제 상태·버튼으로 구성했다.

운영 적용 시 `0018_garden_invitation.sql` 마이그레이션이 필요하다. 이번 작업은 코드·이미지·로컬 검증이며 운영 배포와 네이티브 동기화는 포함하지 않는다.

검증: 관련 10개 테스트 파일의 116개 테스트와 타입 검사가 통과했다. 실제 클라이언트 프로덕션 빌드와 Worker dry run을 별도로 확인했다. 동일한 API 함수와 SQL을 SQLite의 원자적 배치로 실행해 중복 집계·동시 수령·롤백·구버전 호환을 검증했다. 실제 앱 컴포넌트를 사용하는 브라우저 검수에서는 준비, 채팅 공유, 지도 표시 후 방문 기록, 보상, 정자 렌더링, 요청 오류 복구와 320/390/430px·한국어/영어/일본어 표시를 확인했다. 브라우저의 네트워크는 격리된 로컬 fixture이며 운영 데이터나 실제 길드에는 메시지를 보내지 않았다.

검수 로그와 화면: `output/verification/garden-invite-v117/`. D1 배치의 전체 롤백 동작은 [Cloudflare 공식 문서](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)를 기준으로 구현했다.
