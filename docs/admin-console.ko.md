# 구름정원 운영 콘솔

접속 주소: https://puzzle-mobile.ddr1323.workers.dev/admin
최초 소유자: `hiddenstagedev@gmail.com`

## 최초 접속

1. 이 컴퓨터의 `.wrangler/admin-first-login.html`을 열고 **관리자 계정 설정 열기**를 누릅니다.
2. 관리자 이메일과 문자·숫자가 포함된 12자 이상의 비밀번호를 직접 입력합니다.
3. 등록 후에는 일반 `/admin` 주소에서 로그인합니다. 최초 등록 링크는 다시 사용할 수 없습니다.

초기 링크와 `.wrangler/admin-console-secrets.json`은 Git에 포함되지 않는 비밀 파일입니다. 링크를 외부에 공유하지 않습니다. 비밀번호는 대화창이나 소스 코드에 기록하지 않습니다.

변경은 검토 창에서 내용을 확인하고 사유를 적어 적용합니다. 재화 지급은 서버 원장에 기록되며 같은 요청의 재전송으로 중복 지급되지 않습니다. 하트 상한을 넘는 지급은 선물함에 보관됩니다. 새 보상 이벤트는 계정당 한 번 수령할 수 있습니다.

사용자 레벨을 변경하면 해당 사용자의 진행 중인 판이 종료됩니다. 이미 유료 구매자가 있는 패스 시즌의 기간 변경과 활성 시즌 기간 중복은 제한합니다. 기존 패스 구매·보상 기록은 중지 후에도 유지합니다.

## 앱 반영 범위

- 운영 UI를 포함한 새 앱에서 설정 → 공지사항·고객센터·이벤트 보상으로 진입합니다. 이벤트 페이지에서도 운영 이벤트 보상에 진입할 수 있습니다.
- 설정은 접속 시, 앱으로 돌아올 때, 활성 상태에서 60초 간격으로 다시 확인합니다. 게임 타일 계산은 기존 로컬 엔진을 유지합니다.
- 서버도 점검·이용 제한·기능 중지·최소 버전을 검사합니다. 도구 가격은 인증 시 읽은 운영 설정을 재사용하여 불필요한 DB 왕복을 줄입니다.
- 이미 시작된 결제의 검증·정산과 공급자 알림은 점검이나 새 결제 중지 중에도 처리합니다.
- 기존 앱에 없는 공지·고객센터·업데이트 화면은 앱 업데이트가 필요합니다. 최소 버전 검사는 버전 헤더를 보내는 앱에 적용됩니다.
- 버전 정책의 `0.0.0`은 미지정입니다. 실제 배포 완료 버전과 스토어 URL을 확인하고 최소 버전을 설정합니다. 콘솔이 App Store / Play Store 설치 파일을 업로드하는 것은 아닙니다.
- 이벤트 추가·점검·공지·가격 등의 운영 설정은 이후 앱 재빌드 없이 바꿀 수 있습니다. 퍼즐 규칙 코드와 신규 네이티브 기능은 기존 배포 절차를 사용합니다.
- 오늘/7일 지표의 날짜 경계는 UTC이며 화면에 명시합니다. 접속 지표는 운영 연동 이후 수집분부터 집계됩니다.

## 보안과 배포

게임 계정과 관리자 계정은 분리합니다. 비밀번호는 서버 비밀 키와 임의 salt를 사용하여 PBKDF2로 저장합니다. 세션은 8시간, HttpOnly·Secure·SameSite=Strict 쿠키이며 쓰기 요청에는 Origin과 CSRF 검사를 적용합니다. 직원 초대는 24시간 일회용입니다. 비밀번호 변경 시 다른 세션은 종료됩니다. 소유자 계정은 직원 관리 화면에서 비활성화할 수 없습니다.

추가 마이그레이션: `apps/api/migrations/0012_operations_console.sql`. 기존 D1·R2·Durable Object와 Smart Placement를 유지합니다. 관리자 정적 리소스는 동일 Worker의 `ADMIN_ASSETS` 바인딩으로 제공합니다.

일반 재배포: `npm run deploy`. 배포 스크립트는 관리자 화면 빌드 → D1 마이그레이션 → Worker 배포 순서이며 `--keep-vars --strict`를 적용합니다. 대시보드의 추가 환경 변수와 기존 비밀 값은 보존됩니다.

최초 배포에서만 보호된 JSON 파일을 `wrangler deploy --secrets-file`에 전달하여 `ADMIN_BOOTSTRAP_TOKEN`과 `ADMIN_PASSWORD_PEPPER`를 등록합니다. 보호 키를 임의로 교체하면 기존 관리자 비밀번호 검증이 실패하므로 보존합니다.

공식 참고: [Workers Assets 바인딩](https://developers.cloudflare.com/workers/static-assets/binding/), [Workers 비밀 값](https://developers.cloudflare.com/workers/configuration/secrets/).

## 게임 이벤트 운영

이벤트 메뉴의 **게임 이벤트 운영**에서 꽃빛축제·동물 구출 원정·도구 축제·보물 카드의 활성화, 개최 시작/종료 및 해금 레벨을 설정합니다. 날짜 입력은 한국 시간(UTC+9)이며 작업 사유와 함께 검토 후 적용합니다. 꽃빛축제는 신규 참가자의 개인 진행 일수, 동물 구출은 하루 도전 횟수도 조정할 수 있습니다.

동물 구출 원정 기본값은 **10단계·레벨 20 해금·하루 3회**, 한국 시간 **00:00 초기화**입니다. 새 단계 시작·재시도에만 차감하고 이어하기는 무료입니다. 횟수를 바꿔도 오늘 사용한 횟수는 유지합니다. 기존 진행/지급 보상은 지우지 않으며, 마지막 강아지 보상은 별도 지급 ID로 한 번만 지급합니다. 자세한 규칙과 검증 범위는 [강아지 원정 v49](expedition-v49.ko.md)를 참고하세요.

## 시작 아이템 시간 이벤트

이벤트 메뉴의 **시작 아이템 무제한**에서 매일 시작 시각을 설정합니다. 기본은 한국 시간 12:00·18:00·21:00, 매회 10분이며 활성화되어 있습니다. 시작 화면의 로켓·꽃폭탄·무지개등만 소모 없이 선택할 수 있습니다. 중복 시간과 10분 미만 간격은 저장되지 않습니다. 자세한 규칙은 [start-booster-rush.ko.md](start-booster-rush.ko.md)를 참고하세요.

### 원정 회차별 전용 동물 (v50)

동물 구출 원정 카드의 **원정 회차 ID**, **구출 동물 · 완주 보상**에서 판다·여우·레서판다를 회차별로 선택합니다. 기본 첫 회차는 판다입니다. 같은 동물과 ID는 기존 회차를 재사용하며, 새 ID는 새 진행을 엽니다. 기존 원정과 보상, 하루 도전 사용량은 보존합니다. 상세 절차는 `docs/expedition-rounds-v50.ko.md`에 정리했습니다.
