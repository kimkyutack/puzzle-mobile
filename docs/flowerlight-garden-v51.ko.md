# 홈 아이콘·실제 정원 꽃빛축제·카메라 전체 보기

## 동작

- 루미의 기록은 기존 편지 아이콘을 유지하고, 미션은 체크리스트·연필 원화로 구분합니다. 순위는 금색 트로피 원화로 교체했습니다.
- 꽃빛축제는 별도 광장을 꾸미는 방식 대신 실제 소유 정원을 미리 보여 줍니다. 다음 단계 보상에 축제 장식의 이미지·종류·수량을 표시합니다.
- 단계 보상은 실제 정원 모델에 영구 지급하고 열린 땅의 빈 위치에 설치합니다. 기존 건물·동물을 이동하거나 덮어쓰지 않습니다. 공간이 없으면 보관함에 남깁니다.
- 카메라 최소 배율은 0.45에서 0.04로 변경했습니다. 홈·꾸미기의 `전체 보기`는 열린 땅과 실제 장식의 외곽을 화면의 사용 가능한 공간에 맞춥니다. 기본 배율은 유지하며 손가락 기준 확대/축소도 유지합니다.

| 단계 | 실제 정원 보상 |
| --- | --- |
| 축제 입구 꾸미기 | 꽃빛 축제 아치 1개 |
| 꽃길 잇기 | 축제 꽃 화단 4개 |
| 꽃빛 분수 밝히기 | 꽃빛 분수 1개 |
| 축제 쉼터 꾸미기 | 축제 벤치 1개 |
| 꽃빛축제 개막 | 축제 가로등 2개 |

## 저장과 호환

기존 코인·도구 보상, 꽃잎 목표와 개최 기간은 유지합니다. 장식은 고정된 지급 ID로 중복 지급을 막습니다. 기존에 받은 분수의 지급 ID도 그대로 사용합니다. 이미 옮기거나 보관한 물건은 자동 재설치하지 않습니다.

새 보상 수령은 기존 플레이어 변경 트랜잭션 안에서 정원 저장까지 함께 수행합니다. 저장 실패 시 진행·코인·장식을 모두 롤백합니다. 과거 완료한 단계의 누락 장식도 기존 복원 물건과 동일한 정원 투영 과정에서 보충하며, 정원 저장 요청 시 함께 보존됩니다.

새 앱은 정원 요청 및 축제 보상 수령에 `gardenArt=garden-v51`을 보냅니다. 구버전 앱에는 새 아치를 동일한 크기의 기존 장미 아치로 응답에서만 대체합니다. 서버의 정식 장식 종류·소유권·배치는 유지합니다.

## 검증

`output/verification/garden-v51`에 테스트·타입 검사·웹 빌드·Worker dry-run 및 브라우저 검증 결과를 저장했습니다. 실제 SQLite를 사용하는 API 테스트로 새 원화 응답, 구버전 원화 대체, 정원 설치 저장을 확인했습니다. 순수 정원 테스트는 전 단계 설치, 기존 배치 보존, 보관 상태 보존, 공간 부족과 중복 지급을 확인합니다.

격리된 브라우저 데이터로 320/390/540px 홈, 꾸미기 모드, 축제 보상 수령 후 홈의 동일한 인스턴스·위치·축제 변형 유지, 실제 정원 미리보기, 영문 화면을 확인했습니다. 운영 계정은 변경하지 않았습니다. 서버 배포·네이티브 동기화·앱 아카이브는 하지 않았습니다.
