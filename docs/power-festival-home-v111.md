# 홈 도구 축제 v111

이벤트 목록의 도구 축제를 제거하고 홈 도구 축제 모달에 기존 이벤트 장면을 그대로 재사용한다. 새 그림이나 게임 규칙은 추가하지 않는다.

- `event-tabs.ts`, `EventsContent.tsx`: 도구 축제 탭 생성·본문 분기 제거. 기존 초기 탭 ID의 타입은 과거 호출과의 호환용으로 유지하며, 사용할 수 없는 초기 탭은 기존 로직대로 출석 선물로 돌아간다.
- `PowerFestival.tsx`: `PowerFestivalDialog`가 기존 공용 모달과 `PowerFestivalMenu presentation="scene"`을 연결한다. App의 홈 단축키/진행 표시가 여는 기존 메뉴 이름을 유지한다. 퍼즐 이동은 기존 시작 레벨 흐름으로 연결한다.
- `power-festival-modal.css`, `event-scenes-v65.css`: 도구 장면에만 모달 스타일 범위를 추가했다. 배경/네 아이템 목표/게이지/다섯 보상함/타이머/기존 버튼을 그대로 사용한다. 기존 이벤트 본문의390×590.390625 비율을 유지하고 작은 화면에서는 모달 폭도 줄여 내용이 잘리지 않게 한다.
- `attention-state.ts`: 이벤트 탭 유무와 무관하게 홈 축제 상태/알림을 계산한다. 홈 배지·획득한 만료 보상 알림은 유지하고 이벤트 푸터 수에는 축제를 포함하지 않는다.
- `event-discovery.ts`: 홈 전용 축제를 ‘새 이벤트’ 배지의 대상으로 삼지 않는다.

기존 시작/보상 API, 명령 키, 단계 순서, 서버 지급 응답, 도구 사용 집계는 변경하지 않았다. 보물 카드/길드/출석 그림·규칙과 다른 모달은 이번 작업에서 수정하지 않는다.
