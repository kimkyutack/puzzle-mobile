# 서리 바닥과 기존 덩굴 겹침 — v19

사용자 후속 지시에 따라 서리 칸은 밝은 얼음 바닥이 칸 전체를 채우고, 그 위에 원래 색의 타일을 올린다. 타일 전면에는 기존 서리 이미지를 얇게 겹친다. 덩굴은 기존 이미지를 유지한다.

- 기존 서리: `packages/assets/source/frost.png`, 런타임 `frost.85937c2daa0e.png`.
- 기존 덩굴: `packages/assets/source/vine.png`, 런타임 `vine.b65c49a5d190.png`.
- 두 이미지의 픽셀과 SHA-256은 변경하지 않았다. 원본의 투명한 가운데와 기존 모양을 유지한다.
- 불투명한 얼음 바닥은 `packages/assets/source/frost_floor_v19.png`를 1.005셀 크기로 타일 뒤에 깐다. 불투명도는 1이며, 원래 타일 색을 가리지 않고 칸 사이의 빈 공간까지 얼음 바닥이 보인다.
- 기존 서리 전면 이미지는 1.04셀 크기, 한 겹 불투명도 0.24 / 두 겹 0.48로 표시한다. 가운데 타일 색은 유지한다. 별도 눈송이 배지나 코드로 그린 테두리는 제거했다.
- 덩굴과 상자·화분·이끼·저장함 이미지는 일반 타일과 퇴장하는 타일보다 위에 표시한다. 보드 마스크와 최상단 남은 횟수 표시는 유지한다.
- 얼음 바닥과 전면 서리는 실제 타격 시점에 함께 갱신한다. 망치는 760ms 타격까지 유지되고, 모션 줄이기에서는 최종 상태로 즉시 갱신한다. 게임 규칙·이동 가능 여부·서버 데이터는 변경하지 않았다.

## 확인

- 에셋 누락 0개, 기존 서리와 덩굴의 런타임 해시 일치 확인.
- 관련 테스트 5개 파일 24개 통과: 서리·덩굴 타격 시점, 두 겹→한 겹→제거, 보드 마스크, 이펙트 수명, 드래그 판정.
- 실제 Board와 엔진을 사용하는 계정/API 없는 격리 화면에서 390×844 레벨 10의 덩굴과 레벨 13 마지막 서리를 확인했다. 망치 타격 전에는 유지되고 타격 후 해당 표시가 제거되며 입력은 idle로 복귀했다.
- 320×740의 9열 레벨 53에서 두 겹 서리와 모션 줄이기를 확인했다.
- 웹 빌드 및 iOS/Android 웹 리소스 동기화. 설치 앱에는 네이티브 재빌드가 필요하며 실제 기기 설치는 수행하지 않았다.

최종 화면: `output/verification/frost-floor-v19-390.png`, `frost-floor-v19-320.png`. 기존 덩굴 확인: `output/verification/vine-existing-overlay-v18-390.png`.

처음 제작한 강한 덮개 그림은 전면에 사용하지 않는다. 이후 사용자가 칸 전체를 채우는 배경 방식을 제시해, 서리 시안을 배경 전용으로 재사용했다. 내장 image_gen의 원본·정확한 프롬프트와 재사용 경로는 `packages/assets/lock-overlays-v18.json`에 기록했다. 덩굴 시안은 `packages/assets/drafts/lock-overlays-v18/`에만 보관하고 런타임에 포함하지 않는다.
