# 6번째 묶음 — 251~300레벨

이 문서는 최초 300판까지의 제작 기록이다. 현재 공개 범위와 1만 판 단위 생성은 [일괄 확장 문서](campaign-bulk.ko.md)를 기준으로 한다. 아래의 301판 미공개·50판 단위 추가 설명은 당시 상태다.

최대 30,000레벨 캠페인 중 실제 제작·승리 기록 검증 완료 범위를 250판에서 300판으로 확장했다. 새 구간은 50판이며 엔진은 1.3.0, 신규 콘텐츠 버전은 `garden-2026.11.04-campaign-pack6-v21`이다. 기존 1~250판의 전체 정의, 실행 시 복원 결과, 레시피, 승리 기록은 동일하게 유지한다.

## 다섯 가지 공략

| 구간 | 구성 | 공략 |
|---|---|---|
| 251~260 | 꽃봉오리 + 물관 + 씨앗 배달 | 꽃에서 나온 씨앗 아래의 물관을 줄여 출구까지 길을 연다. |
| 261~270 | 차양 + 꽃봉오리 + 씨앗 배달 | 지정 색을 모아 아래쪽 차양을 걷고 씨앗을 내려보낸다. 차양이 남아 있으면 씨앗은 출구에 도달할 수 없다. |
| 271~280 | 회전 화분 + 물관 | 이동 화분의 다음 위치와 물관 제거를 함께 고려한다. |
| 281~290 | 측면 차양 + 회전 화분 | 차양 뒤의 공간을 열면서 움직이는 화분을 공략한다. |
| 291~300 | 차양 + 물관, 어려운 판은 꽃봉오리·씨앗 추가 | 앞에서 익힌 규칙들을 함께 사용한다. |

9열 너비를 유지하며 보드 높이, 모서리, 계단, 협곡, 가운데 빈칸 등을 조합한 실제 형태는 15가지다. 씨앗이 나오는 열은 출구까지 끊기지 않도록 보존하고 화분 경로에는 빈칸이나 다른 장치를 배치하지 않는다. 목표 종류는 최대 4개다.

## 난이도와 검증

10판마다 쉬움 → 보통 → 보통 → 어려움 → 쉬움 → 보통 → 보통 → 매우 어려움 → 쉬움 → 연쇄 축제를 반복한다. 50판 안에 쉬운 판 15개, 보통 20개, 어려움 5개, 매우 어려움 5개, 연쇄 축제 5개가 있다. 260/270/280/290/300판에는 인벤토리를 사용하지 않는 시작 특수 타일 3개가 포함된다.

50판 모두 교환·특수 타일 탭만으로 클리어하는 기록을 확보했다. 시작 선택지 3개 이상, 초기 자동 매치 없음, 클리어 중 강제 섞기 없음, 승인 레시피 복원 일치를 확인한다. 승리 기록은 봇의 통과 가능성 검증이며 사람의 난이도·승률 측정은 아니다.

기존 250판의 보존 여부는 `tests/fixtures/campaign-pack5-hashes.json`에 고정한 SHA-256과 정의·레시피·실행 결과·승리 기록을 비교한다. 새 구간의 조합, 모양, 난이도 완급, 공짜 시작 아이템, 씨앗 출구와 차양의 선후관계는 `tests/campaign-pack6.test.ts`에서 확인한다.

현재 전체 300판 레시피는 2,101바이트이며, 기존 250판 대비 350바이트 늘었다. 전체 보드와 승리 기록은 개발 검증 자료로 보관하고 앱에는 승인 레시피와 생성 규칙을 포함한다. 이동·폭발은 로컬 공통 엔진에서 실행한다.

## 추가 제작과 적용 범위

`npm run levels:campaign:verify`로 300판 전체를 재검증할 수 있다. `npm run levels:campaign:build`는 현재 공개 구간을 유지해 검증한다. 다음 묶음은 공략을 기획하고 별도의 생성 규칙을 등록한 다음 `--to=350`으로 추가한다. 등록하지 않은 묶음은 `CAMPAIGN_PACK_NOT_AUTHORED`로 거절하며, 게임의 미공개 구간은 301판부터다.

새 원화나 경제 기능은 추가하지 않았으며 기존 네 가지 기믹 이미지를 사용한다. 운영 Worker 배포, 원격 DB 변경, iOS/Android 설치본 갱신은 이번 작업에서 수행하지 않았다.

## 이번 확인 결과

- 전체 42개 테스트 파일, 291개 테스트 통과. 타입 검사 및 웹 프로덕션 빌드 통과.
- 300판 전체의 시작 상태, 중복, 승인 레시피, 구매 없는 승리 기록 재검증 통과. 기존 250판의 정의·실행 결과·레시피·증명 기록 해시 일치.
- 실제 Chrome 격리 검수에서 251판 9수, 261판 4수, 271판 2수, 281판 2수, 298판 35수로 입력해 클리어 확인. 각 기록은 승인된 자동 플레이 경로를 UI로 재현한 것이며 사람 난이도 평가가 아니다.
- 320×740에서 네 목표와 이동 숫자가 각 영역 안에 있고 수평 넘침이 없는 것을 확인. 390×844에서도 다섯 공략 유형의 실제 보드를 확인했다.
- 화면·조작 단계·검수 결과는 `output/verification/campaign-pack6-browser/`, 전체 콘텐츠 보고서는 `output/verification/campaign-v20.json`에 저장했다. 실제 네이티브 설치본과 운영 API 검수는 수행하지 않았다.
