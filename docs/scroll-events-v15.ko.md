# 스크롤·이벤트·목표 여백 수정

- `ArtSurface`의 UI 테두리를 별도 Pixi 캔버스에 매 프레임 재배치하던 방식을 없앴다. 동일한 원본 PNG를 각 `data-frame` 요소 안에 CSS nine-slice로 붙인다. 글자·프레임이 같은 네이티브 스크롤 영역을 따라가며, 페이지/모달 클리핑도 브라우저가 함께 처리한다. 배경은 원본 이미지를 유지한다. 보드와 정원 월드의 Pixi 렌더러는 변경하지 않았다.
- 프레임 생성/변경/삭제와 크기 변경을 관찰하고, 스크롤 이벤트나 위치 보정 애니메이션은 사용하지 않는다. 언마운트 시 DOM/관찰자/예약 작업과 임시 스타일을 정리한다.
- 이벤트 첫 화면의 일일·주간 미션 진입점을 제거하고 출석 선물과 보물 카드를 배치했다. 미션은 홈에 유지하며 푸터 이벤트의 알림에는 미션 수를 합산하지 않는다.
- 기존 하루 한 번 50코인 선물을 7일 누적 출석으로 확장했다. 7번째 수령 시 귀속 망치 1개를 추가한다. 기존 `reward_claims` 기록으로 누적하며 빠진 날은 초기화하지 않는다. 기존 서버 날짜 경계(UTC 자정, 한국 오전 9시)를 유지한다. DB migration은 없다.
- `GET /events`에 attendance 메타데이터를 추가했고 `POST /events/daily`의 기존 중복 방지 트랜잭션 안에서 추가 망치를 지급한다. 구버전의 일일 선물 요청도 같은 출석으로 집계하므로 두 번 지급되지 않는다.
- 목표 제목의 위쪽 inset은 8px에서 16px로 늘리고 목표 아이콘/숫자 행을 따로 확보했다. 다중 목표 행도 같은 기준으로 조정했다.

검증:
- 타입 검사·번역 검사·프로덕션 웹 빌드 통과.
- 37개 파일 전체 테스트에서 262개 통과, 기존 긴 리플레이 검사 3개가 병렬 실행 시간 제한(30초)에 걸렸다. 해당 3개 파일을 워커 1개로 재실행하여 16개 검사 모두 통과했다. 최종 모든 265개 검사는 각각 통과했다.
- 임시 Miniflare/D1 HTTP 검사 5개: 누적 출석, 7번째 추가 보상, 재시도·중복·동시 수령 방지.
- 390×844 및 iPhone 안전 여백을 사용한 격리 UI: 이벤트·상점·길드·설정 모달에서 스크롤 후 프레임/내용 위치 차이 0px, React 상태 변경 후 중복 프레임 0개, 출석 완료/빨간점 해제, 목표 제목 inset 16px 확인. 화면은 검수 전용 데이터를 사용하며 실사용자 데이터를 읽지 않는다. 실제 iOS 관성 스크롤 재검증은 별도다.
- 승인된 출석 API만 운영 Worker 직접 배포: version `7d301712-90f9-4aed-9b09-f695750f1652`. 새 검증 게스트의 실제 첫 수령/중복 차단/완료 상태를 확인하고 계정·인증 파일을 정리했다.

Git 커밋·푸시는 수행하지 않았다. 메인 대화에서 진행 중인 타일 작업과 함께 앱을 다시 빌드할 때 UI 변경이 포함된다. 이번 작업에서 네이티브 설치나 앱 데이터 초기화는 수행하지 않았다. 다음 Git 기반 Worker 배포 시 `apps/api/src/attendance.ts`와 `economy.ts` 변경이 함께 포함되어야 출석 기능이 유지된다.
