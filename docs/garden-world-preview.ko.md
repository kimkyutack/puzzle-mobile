# 정원 지도 체험 화면

최신: 실제 홈 연결은 `garden-world-live-home.ko.md`를 참고한다. 아래 내용은 독립 미리보기 단계의 기록이다.

최신 확장: 장식6종·동물3종과 무료 체험 상점, 실제 구매→드래그 배치→저장 복원 검수를 추가했다. 현재 범위와28검사 결과는 `garden-world-decoration-expansion.ko.md`를 참고한다. 아래의20검사 및 브라우저 연결 실패는 최초 지도 미리보기 단계의 기록이다.

2026-11-03, 큰 정원 지도의 첫 조작 미리보기. 기존 게임 화면과 별도로 열며 실제 계정·재화·복원 상태·API를 사용하지 않는다.

실행 중인 독립 미리보기: http://127.0.0.1:5192/

## 이번 단계

- 등각 격자32×32지도, 드래그 카메라, 두 손가락/휠/버튼 확대·축소, 구역 바로가기.
- 새 원화8종: 잔디, 산책로, 분수, 온실, 벤치, 꽃 화단, 가로등, 나무. 각각 따로 생성했고 원본과 정확한 프롬프트를 `packages/garden-world/art/prompts.json`에 보존했다. built-in image_gen을 사용했다. 잔디 반복에서 발견한 밝기 줄무늬는 원화 편집으로 줄였고 이전 초안도 보존했다.
- 보관함→반투명 미리보기→이동/방향→배치. 기존 물건의 이동·회수·재배치. 땅 점유/지도 밖/잠긴 구역은 확정 불가. 산책로와 물건은 별도 층이고 같은 층끼리 겹칠 수 없다.
- 보관함을 열면 남은 보유 사본 수를 표시한다. 배치는 보유량을 복제하거나 새 아이템을 생성하지 않는다. 미리보기 취소는 저장하지 않는다.
- 별도 체험 키 `cloud-garden-world-preview-v1`에만 배치 저장. 손상되거나 다른 소유자의 체험 데이터는 기본 정원으로 복구한다. 실제 게임 세션 키·진행·서버 데이터에는 접근하지 않는다.
- 방문 화면 체험에서는 현재 체험 정원을 둘러볼 수 있고 편집/보관함은 제한한다. 실제 다른 플레이어의 프로필·순위·공개 정원 API 연결과는 구별한다.

## 실행과 파일

개발 서버에서도 `http://127.0.0.1:5173/garden-world.html`로 열 수 있다. 독립 빌드는 아래 명령으로 만들고 실행한다.

```sh
node --import tsx tools/garden-world/build-art.ts
node tools/garden-world/build-preview.mjs
node tools/garden-world/serve-preview.mjs
```

결과는 `output/garden-world-preview/`이며 기존 `apps/client/dist`나 네이티브 public을 빌드/동기화하지 않는다. 독립 서버는127.0.0.1:5192에서 정적 파일만 제공한다. `/api` 처리기는 없다. UI 원화는 기존 승인된 PNG의 사본을 사용하고 폰트/OFL을 함께 제공한다. 공유 메인 UI·API·DB·패키지 설정은 이번 단계에서 변경하지 않았다.

## 검증과 한계

- 기반/체험 상태20검사 통과: 합법 초기 배치67개, 사본 보존, 회전/점유/잠긴 구역, 중복 요청, 방문자 변경 거부, 기기 저장 복원·손상 데이터 대응, 합법 시작 자리 탐색, 카메라 좌표와 줌 수학.
- TypeScript 및 별도 Vite 빌드 통과. 폰트는 미리보기 번들에 직접 포함한다.
- `tools/garden-world/verify-preview.mjs`는 빌드의 모든 파일을 로컬 HTTP로 읽어 원본 바이트와 비교하고 API 부재를 확인한다. 결과는 `output/verification/garden-world/http-build.json`.
- 원화/배치 별도 렌더는 `output/verification/garden-world/art-review.png`, `map-layout-review.png`. 후자는 실제 배치 데이터·좌표로 제작한 오프라인 그림이며 브라우저 스크린샷이 아니다. 격자 표시·터치/스크롤·DOM 레이아웃 검증을 대신하지 않는다.
- CUA의 첫 페이지 연결에서 앱의 실제 DOM 로드를 확인했으나 후속 브라우저 탭 연결은 반복 timeout/kernel reset으로 실패했다. 네이티브 Chrome 조회도 장시간 지연되었고 사용자 다른 창에는 조작하지 않았다. 최종 화면의 실제 포인터/핀치·작은 화면 정렬·콘솔·기기 검수는 미완료다. 이를 통과 결과로 주장하지 않는다.
- 이 단계는 조작 미리보기다. 메인 홈 연결, 기존 복원 보유권 이관, 서버 권위 저장, 실제 정원사 방문, 상점 상품/결제 연결, 방향별 추가 원화·물/주민 애니메이션은 후속 통합 범위다.
