# 허브 본문 로딩 v111

상점·친구·길드·이벤트의 공통 헤더와 푸터를 유지하고 내용만 준비한다. 이벤트는 첫 응답 전에도 기존 이벤트 탭을 표시한다. 탭을 먼저 선택하면 데이터 도착 후에도 그 선택을 이어 간다. 최초 방문의 이벤트 본문에는 기존 선물 상자/별빛 이미지를 중앙에 두고 부드럽게 움직이며, 짙은 청록색 이벤트 재질 배경으로 단색 빈 공간을 채운다. 친구/길드/상점/패스/랭킹도 기존 그림과 페이지 구조 안에서 내용을 준비한다.

## 구현과 범위

- `EventTabsBar.tsx`: 기존 이벤트 탭 markup과 가로 스크롤/키보드 탐색을 공용으로 분리한다. 준비 중과 준비 후의 tab/panel ID 관계, 선택 및 이벤트 재진입 reset을 유지한다. 데이터가 없을 때 수량/보상은 만들어 표시하지 않는다.
- `EventsContent.tsx`, `CommunityMenus.tsx`: 데이터가 없을 때에도 탭+본문 로딩을 렌더링한다. 홈에서 이미 확인한 Activity snapshot이 있으면 즉시 재사용한다. 실패한 새 요청은 기존 내용을 지우지 않고 짧은 안내와 재시도로 표시한다. 보상은 이번 방문의 `/events` 확인 전 비활성화한다. 오래된 응답과 이전 계정/해제된 화면의 응답을 무시한다.
- `HubLoading.tsx`, `hub-loading.css`: 기존 raster 선물/캐릭터/문장과 반짝임, 부드러운 이동/확대 효과. 그림 아래 안내,6초 이후 연결 지연 안내와 재시도. OS 및 앱의 움직임 줄이기를 지원한다. 밝은 페이지에는 남색, 청록색 이벤트에는 밝은 문구를 사용한다.
- `page-snapshots.ts`: 계정+페이지별로 최대16개,5분간 메모리에만 보관한다. 재방문에 이전 목록/카탈로그/길드/이벤트가 즉시 나타나고 최신 데이터는 별도로 확인한다. 세션 변경에 메모리 캐시를 비운다. 이 캐시는 보상/구매/가입 권한의 근거가 아니다.
- `FriendsMenu.tsx`, `ShopMenu.tsx`, `RankingMenu.tsx`: 페이지별 캐시와 본문 로딩 적용. 친구 조작 및 상점 구매는 현재 방문의 서버 응답 확인 후 활성화한다. 상점은 기존 도구 선반을 먼저 보여주고 카탈로그를 확인한다. 구매 가격/스토어 검증, 기존 API, 재시도/idempotency 흐름은 유지한다.
- `event-tabs.ts`: 로딩 중에는 시즌 진행 데이터 없이 탭 구조만 계산할 수 있다. 실제 진행이 제공되면 기존 알림 조건을 그대로 사용한다.
- `localized-copy.ts`: 지연/최신 정보 확인 실패 문구의 영어·일본어를 추가했다.

출석/보물 카드의 이미지·규칙·서버 보상, 기존 푸터와 모달 디자인은 이 작업에서 편집하지 않았다. 새 API나 패키지는 추가하지 않았다.

## 검증

`output/verification/hub-loading-v111/app.html`은 실제 App을 사용한다. 별도 init.js가 로컬에서만 응답 지연/실패/보류를 재현하며 운영 API는 호출하지 않는다.

- `browser.json`:26개 확인. 첫 응답 전 탭/푸터 표시, 로딩 중 선택 유지, 지연 안내, 재방문 이벤트/친구/길드/상점 내용 유지, 확인 전 보상/구매 비활성, 확인된 출석 요청1회, 최초 실패/캐시 갱신 실패 후 재시도,320×568/390×844/430×932/768×1024 및320px 영어·일본어, 움직임 줄이기, runtime page error0.
- `final-polish.json`: 밝은 친구 로딩의 남색 문구와 OS 움직임 줄이기를 마지막으로 재검증했다. `footer-diff.json`에서 같은 DOM의 전용 CSS on/off 전후 푸터 픽셀 차이0.
- `polish.log`는 길드 최초 실패→재시도와 오류 안내44px 버튼을 확인한 뒤, 새 검수 문서의 App 시작이30초 내 끝나지 않아 마지막 친구 캡처에서 시간 초과했다. 이미 열린 화면에서 진행한 `final-polish.log`가 해당 최종 대비/동작 확인 근거다. 검수 도구의 문서 시작 지연과 제품의 본문 로딩을 구분했다.
- `tests.log`: 캐시의 계정 분리/만료/용량/초기화, 기존 이벤트 탭/번역 검사25건 통과.
- `build-final.log`: TypeScript와 production build 통과. 마지막 CSS 보정 후 `vite-final.log`도 통과. 기존 큰 청크 안내는 남는다.
- 변경 파일 `git diff --check` 통과.

실제 서버/느린 한국 통신망/실기기 WebView/스토어 결제는 검수하지 않았다. 운영 배포·네이티브 동기화는 실행하지 않았다. 앱 재시작 후에도 남는 영구 데이터 캐시는 추가하지 않았다.
