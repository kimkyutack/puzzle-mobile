# 입체 타일과 씨앗 저장함

일반 타일 6종은 밝고 진한 색면에 둥근 면 굴곡, 깎인 모서리, 하단의 깊이, 작은 반사를 더한 젤리 보석 형태로 바꿨다. 9열 기준 크기와 v15에서 조정한 칸 간격을 사용한다. 원본은 `packages/assets/source/tile_block_*_v16.png`, 내장 image_gen의 정확한 프롬프트와 출처는 `packages/assets/tile-set-v16.json`에 있다.

문처럼 보이던 물체는 두 칸을 차지하는 씨앗 저장함이다. 기존 이미지 정규화가 넓은 아이콘에도 가로 크기의 9%를 사방에 넣으면서, 실제 불투명 이미지가 두 칸 면적의 일부만 차지했다. 새 `cabinet_v16.png`는 씨앗 표시가 있는 2:1 상자 원본이다. 추가 아이콘 여백 없이 512×256으로 정규화하고, 보드에서 두 칸 전체 크기의 98%로 배치한다. 숫자는 저장함 전체의 오른쪽 아래에 표시하며 기존 최상단 숫자 레이어를 사용한다.

숫자는 남은 내구도이며 마지막 1까지 표시한다. 주변 매치 또는 특수 타일로 저장함을 열면 씨앗이 나온다. 표시 이름과 도움말도 씨앗 저장함으로 정리했다. 기존 퍼즐 상태, 색 ID, 목표와 타격·씨앗 방출 판정은 동일한 로컬 엔진을 사용한다.

검수는 기존 `tools/tile-scale-v15-fixture.html?level=38&capture=1`에서 실제 Board와 로컬 엔진으로 진행한다. `data-obstacle-art-bounds`에는 렌더된 이미지와 숫자 좌표를 기록하여 두 칸을 채우는 크기를 확인할 수 있다. 이미지 팩은 `garden-2026.11.04-sculpted-v16`이다.
