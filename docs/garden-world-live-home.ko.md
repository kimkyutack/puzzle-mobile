# 실제 홈 정원 지도 적용

## 2026-11-05 홈 시설 선택의 카메라 이동 수정

홈에서 기존 시설을 선택하면 편집 진입 효과가 선택한 시설과 무관한 다음 복원 위치로 카메라를 옮기던 문제를 수정했다. 시설 선택·이동 미리보기·취소·편집 닫기는 현재 시점과 확대 배율을 유지한다. 복원 탭을 직접 누르면 다음 작업 위치를 안내하고, 확장 탭을 닫은 뒤 홈에서 시설을 눌러도 해당 시설의 도구를 정상적으로 연다.

시설 선택의 취소·이동·보관은 모두 테두리를 포함해 50px 높이로 맞췄다. 다른 색상 버튼에 적용되던 54px 최소 높이의 간섭을 막고 버튼 원화의 모서리 분할값도 통일했다. 선택 카드에는 하단 메뉴용 이미지를 늘리는 대신 전용 카드 이미지의 모서리를 보존하는 9분할을 사용하며, 밝은 카드 배경에 맞춰 글자는 어둡게 표시한다. 여러 줄로 표시되는 구매 버튼의 높이는 별도 레이아웃을 유지한다.

390×844·320×568 브라우저에서 카메라 10개 흐름과 세 버튼의 높이·위아래 정렬·텍스트 넘침을 확인하고 관련 6개 테스트 파일·33개 테스트를 통과했다. iOS는 배포된 소스 `1f1f8fe`에 카메라와 카드 수정만 더한 운영 API용 번들을 만들고 514개 파일의 복사 일치를 확인했다. iOS 버전은 1.04 (5)를 유지하며 아카이브와 설치는 수행하지 않았다. 서버 API 변경은 없다. 검증 자료는 로컬 `output/verification/garden-camera-fix/`에 보관한다.

2026-11-05 후속: 정원 꾸미기 → 확장에서 1,000골드 고정 비용으로 20칸씩 구매할 수 있다. 새 땅의 배치·산책·저장과 운영 검증은 [골드로 정원 확장](garden-land-v28.ko.md)에 기록했다.

2026-11-04 후속: 꾸미기 아이템의 네 방향 원화·배치·연속 설치·저장 검증을 추가했다. [네 방향 꾸미기](garden-directions-v24.ko.md)에 현재 동작과 운영 반영 결과를 기록했다.

2026-11-04 후속: 동물 산책·휴식과 면적별 방문객, 수량 구매·드래그 연속 설치를 추가했다. 현재 동작과 운영 적용 내역은 [정원 산책과 여러 개 꾸미기](garden-life-and-brush.ko.md)에 기록했다. 아래 정적 동물 설명은 최초 통합 시점의 기록이다.

## 2026-11-03 홈 메뉴 정리

상단 이야기 바와 옆의 다음 정원 버튼, 우측 확대/축소 도구를 제거했다. 지도는 기존 드래그·핀치로 조작한다. 이야기는 좌측 편지 아이콘과 읽지 않은 이야기 배지로 옮겼다. 좌측에는 이야기·패스·순위·무료 선물, 우측에는 한정 패키지·연쇄 패키지·선물함을 배치한다. 타임 특가는 `/offers`에서 현재 판매 가능한 상품이 있을 때만 추가한다. 패키지 아이콘은 기존 상품 구성 이미지를 활용하고 실제 판매 종료 시각에서 남은 기간을 표시한다. 홈 바로가기는 해당 상품 분류가 선택된 패키지 화면으로 연결한다. 캔버스 측정 전에 들어온 카메라 초점 요청은 최초 크기 측정까지 보류하여 첫 홈이 비어 보이는 문제도 보정했다.

아이폰 설치본에서 한정/연쇄 직접 진입과 홈 복귀를 확인했다. 새 증거는 `shortcuts-final.png`, `shortcuts-chain.png`, `shortcuts-report.json`에 기록했다. 기존 자료의 `ios-final.png`는 이전 홈 배치를 보여 준다.

2026-11-03. 독립 미리보기와 달리 실제 게임의 `HomeHub`가 `HomeGardenWorld`와 `WorldMap`을 사용한다. 기존 고정 배경 위의 `GardenScene` 배치는 홈에서 제거했다. 공통 헤더, 스토리, 퍼즐 진입과 상점·친구·홈·길드·이벤트 페이지 이동은 유지한다.

홈에서 드래그·핀치·확대/축소로 32×32 지도를 탐색한다. 정원 꾸미기에서 복원, 보관함, 정원 상점을 선택한다. 구매 후 위치를 미리 보고 확정하며, 배치를 취소해도 구입한 물건은 보관함에 남는다. 이동·방향 전환·보관은 소모 없이 처리한다. 동물은 현재 타일에 배치하는 정적 이미지다.

기존 복원 내역을 안정적인 `restored-<task>` 인스턴스로 투영한다. 입구 복원에 연결된 광장 포장 49칸도 이관한다. 아직 복원하지 않은 시설이나 체험용 인벤토리는 지급하지 않는다. 이동하거나 보관한 복원 시설은 재접속 시 원래 위치에 다시 생기지 않는다. 새 복원의 기본 위치가 이미 사용 중이면 물건만 보관함으로 지급한다. 기존 자연·축제 스타일 기록과 변경 기능도 유지한다.

서버는 `/garden/world`, `/garden/world/commands`, `/garden/shop/buy`를 제공한다. `0010_garden_world.sql`의 별도 테이블에 소유·배치·구역·지급 기록을 저장한다. 읽기와 배치는 Player의 재화나 버전을 변경하지 않는다. 구매는 서버 가격으로 코인을 차감하고, 원장·지급·정원을 동일 D1 배치에서 저장한다. 계정 인증, 소유권, 전체 점유 칸, 구역, 리비전 및 중복 요청을 검사한다. 계정 삭제 시 정원 상태도 정리한다. 상점의 시설·장식·동물 14종 가격은 `packages/garden-world/src/live.ts`에 정의했다.

기존 로컬 D1은 먼저 `.wrangler/backups/garden-home-*.sqlite`로 일관된 백업을 만들었다. 이관 및 iOS 덮어 설치 후 기존 90명 Player의 전체 데이터·버전 해시와 거래 원장 수가 동일함을 대조했다. 실제 사용 계정은 레벨 33, 코인 2,150, 별 6, 복원 15개를 유지한다. 테스트 구매는 분리된 임시 Worker/D1의 별도 계정에서만 수행했다.

검증:

- 전체 Vitest 30파일·208검사 통과, 타입 검사 통과.
- `tools/api-garden-world-http.ts`: 실제 Worker HTTP와 분리된 D1에서 이관, 이동/보관 재조회, 중복 구매, 단일 차감, 점유 충돌, 소유권, 리비전, 가격 위조, 잔액 부족, 계정 삭제 검사.
- 실제 홈 코드를 별도 검수 서버에서 실행해 아이폰 크기에서 토끼 구매·배치와 재접속 후 잔액 유지, 지도 드래그·확대, 이미지 버튼 표시 확인.
- `npm run native:local`, iOS Simulator 빌드 및 기존 앱에 덮어 설치 완료. 설치된 public 365파일·109,796,051바이트가 최종 번들과 SHA-256으로 일치한다.
- 증거: `output/verification/garden-world/live-home/`의 HTTP 보고서, 보존 대조, 설치 파일 대조, 브라우저 캡처 및 `ios-final.png`. iOS 최종 캡처는 실제 사용 계정 화면이며 테스트 구매가 반영되지 않은 상태다.

독립 `garden-world.html`과 5192번 체험 화면은 개발용으로 유지한다. 거기서 받은 무료 체험 장식은 실제 계정 소유권으로 가져오지 않는다. 원격 Cloudflare 배포는 수행하지 않았다. Android 프로젝트에는 동일 번들을 동기화했으며, 현재 실행 중인 Android 기기는 없어 설치 확인은 iOS에서 수행했다.
