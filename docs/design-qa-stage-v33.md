## 발견 사항과 수정 이력

1. **[P1, 해결] 경로 진행이 타일에 가려짐.** 기존 SVG는 중앙을 마스킹하고 열린 칸에도 타일을 다시 채워 물길과 토끼 이동을 알아보기 어려웠습니다. 새 규칙은 연결된 길을 빈 바닥으로 유지하고, 실제 PNG 바닥을 타일 아래에 깝니다. `water-final-390.png`에서 두 화단까지 열린 파란 물길과 아직 남은 흙더미를 동시에 확인했습니다. `animal-60-open-path.png`에서 열린 L자 길과 토끼의 이동 위치를 확인했습니다. 기존 1.6 저장 판은 규칙을 보존하며 물길 이미지만 타일 아래에서 갱신합니다 (`retained-16-water.png`).
2. **[P1, 해결] 도착 과정을 보기 전에 결과가 나옴.** Board의 시각 완료 시간에 물 흐름/토끼 이동/개화 시간과 도착 후 여유를 포함했습니다. 실제 브라우저의 `animal-60-timeline.json`에서 집 도착은 67,097ms, 승리 모달은 67,653ms였습니다. `water-50-timeline.json`에서 3개 화분 개화는 92,562ms, 모달은 93,120ms였습니다. 두 경우 도착·개화 전에는 승리 모달이 없었습니다. 값은 해당 QA 세션 시작 후 상대 시각이며 기기 간 성능 수치가 아닙니다.
3. **[P2, 해결] 작은 흙더미.** 처음에는 정사각형 런타임 이미지의 투명 여백과 contain이 중복돼 장애물이 너무 작았습니다. 실제 넓은 비율로 런타임 크기를 변경했습니다. 최종 `comparison-gate-detail.png`, `animal-60-start.png`에서 타일 아래쪽을 덮는 흙더미가 명확히 구분됩니다.
4. **[P2, 해결] 그림 스타일 불일치.** 납작한 SVG 선·삼각형·집 대신 개별 생성한 입체 PNG를 사용했습니다. 수도꼭지/닫힌 화분/핀 꽃/집/흙더미와 경로가 같은 색상·석재·조명 방향을 공유합니다. CSS는 이미지 위치와 투명도, 회전·이동에만 사용합니다.

## 필수 시각 요소

- **폰트/문자:** 기존 Jua/Lilita One 체계와 실제 레벨·목표·횟수 표시를 유지했습니다. 별도의 영어 보조 라벨은 추가하지 않았습니다. 안내 모달의 문장은 카드 안에서 줄바꿈됩니다.
- **배치/간격:** 기존 헤더/푸터/보드 프레임을 유지합니다. 길은 정확히 셀 좌표를 사용하며 직선·모서리·십자 이미지를 회전해 연결합니다. 열린 칸은 빈 바닥이고 닫힌 경로의 일반 타일 크기 구분은 유지합니다. 소스와 목적지 장식은 보드 안쪽에서 잘립니다.
- **색:** 기존 진한 타일과 파랑/금색 UI에 맞춰 따뜻한 꿀색 돌 경계, 흙색 마른길, 선명한 파란 물을 사용했습니다. 초록/청록/보라색 UI 테마를 새로 입히지 않았습니다. 닫힌 화분과 개화한 화분을 실제 다른 이미지로 구분합니다.
- **이미지:** 실제 alpha PNG 11개를 기존 검증·해시·패킹 파이프라인에 넣었습니다. 바닥 원본의 정사각 좌표계를 trim하지 않아 셀 입구 위치를 유지합니다. 일반 타일·토끼·프레임은 기존 실제 게임 이미지를 재사용합니다. 배경이나 장식을 SVG/문자/그라데이션 그림으로 대체하지 않았습니다.
- **문구/내용:** 흙마개 위 타일을 맞춰 길을 연결한다는 설명과 실제 꽃/토끼 목표가 일치합니다. 첨부된 60레벨은 토끼 길이며 50레벨은 세 화단의 물길입니다. 물길 50에서 2개 개화 후 목표 1개가 남아 플레이가 계속됐습니다.
