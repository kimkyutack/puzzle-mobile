- 402×874: 두 장면 모두402×613.484375, panel clientHeight/scrollHeight613/613, 가로 넘침/표시 이미지 누락/원시 템플릿 없음.

- 개인 보상 수령 → 체크/수령 완료, 길드 보상 수령 → 체크/수령 완료 및 시즌 알림 제거.
- 도구 보상 수령 → 다음 단계 목표/게이지, 이전 선물 체크, 플레이 버튼으로 전환.
- 도구 축제 시작 → 이벤트 생성/카운트다운/플레이 버튼 확인. 전체 완료는 비활성 Done today 표시.
- 시즌 퍼즐 플레이 → 기존 레벨 시작 경로 확인.
- 시즌 없음은 준비 중 안내와 정상 퍼즐 플레이 경로를 표시.
- UI 검수는 fail-closed synthetic fixture를 사용했다. 실제 운영 DB/보상 지급/네이티브 앱을 검증한 것이 아니다. 기존 도구 provider의 요청/수령 처리와 시즌 claim callback을 유지했다.
- 검수 시작 이후 해당 탭의 새 error/warn 로그0 (`console.json`).
