# 새 판 랜덤 배치와 정원 길 스테이지 수정

2026-11-06. iOS/Android 1.05 (6) 아카이브 준비용입니다.

## 재도전과 이어하기

앱은 `/runs/start`에 `randomStart: true`를 보냅니다. 서버는 미리보기의 지형·장애물·목표·이동 횟수와 보호 칸·특수 타일을 유지하고 일반 타일 색과 refill seed만 새로 정합니다. 초기 자동 매치와 교환 불가 여부를 검증합니다. 미리보기 해시는 작성된 맵을 검증하고, 실제 판의 랜덤화된 정의는 `Run.level`에 저장·반환합니다. 앱과 서버는 그 정의로 같은 결과를 재생합니다. 시작 요청에서 solver나 추가 DB 조회를 실행하지 않습니다.

종료·포기한 뒤 새로 시작한 판만 새 배치를 받습니다. 시작 응답 유실 후 같은 키 재시도와 진행 중인 판의 이어하기에는 같은 정의·배치·seed·횟수를 반환합니다. 아직 배우지 않은 튜토리얼의 첫 배치는 고정하고, 해당 도움말 학습 후 재도전에서는 일반 타일을 바꿉니다. `randomStart`를 보내지 않는 구 앱의 동작은 유지합니다.

이 검증은 모든 랜덤 배치의 클리어 가능성·사람의 성공률 인증을 뜻하지 않습니다. 시작 시 자동 매치·진입 불가를 막고 공개 맵의 목표·구조를 유지합니다.

## 물길과 토끼 길

첨부된 60레벨은 물길이 아니라 토끼 길 스테이지입니다. 10·30·50 등은 물길, 20·40·60 등은 토끼 길입니다.

기존에는 열린 길에도 일반 타일이 다시 차고, 경로 SVG의 가운데가 타일용 마스크로 가려져 진행이 보이지 않았습니다. 새 `1.7.0` 규칙은 연결된 길을 빈 바닥으로 유지합니다. 흙마개가 없는 칸을 수원/출발점부터 연결한 경우만 물이 흐르거나 토끼가 이동하며, 떨어진 흙마개 하나를 제거했다고 목표를 달성하지 않습니다. 중력과 refill도 열린 칸에 타일을 놓지 않습니다.

현재 게임의 금색 테두리·입체 타일과 어울리는 실제 PNG 11개를 생성했습니다. 직선·모서리·십자의 마른길/물길, 흙더미, 수도꼭지, 봉오리/개화한 화분, 토끼 집입니다. 토끼는 기존 정원 토끼 이미지를 사용합니다. 바닥은 타일 아래에 깔고 새로 열린 구간은 매치 연출 뒤 드러냅니다. 토끼 이동·물 흐름·도착/개화가 끝난 뒤 결과 모달을 엽니다. 길을 바꾼 뒤 다음 입력은 연출이 끝나면 다시 받습니다.

기존 1.0~1.6 규칙과 저장된 판은 변경하지 않습니다. 1.6 저장 판의 타일 유지 규칙도 보존하며, 그 판의 물길은 타일 아래에서 갱신합니다. 1.7의 별도 24개 스테이지 조합은 유료 도구나 강제 섞기 없는 승리 로그로 인증했습니다. 최초 물길/토끼 길 튜토리얼의 교환도 해당 인증 배치에 맞췄습니다.
