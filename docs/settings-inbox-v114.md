# 설정 선물함 통합 v114

홈의 선물함 바로가기를 제거했다. 설정 모달의 기존 ‘이벤트 보상’ 행을 ‘선물함’으로 교체하고 기존 우체통 아이콘과 일반 선물/이벤트 보상 알림 점을 연결했다. 설정의 다른 메뉴와 본문, 기존 푸터, 앞서 수정한 패널 모서리는 유지한다.

새 GiftInbox는 서버의 `/gifts`와 운영 snapshot의 미수령 reward 이벤트를 한 화면에 표시한다. 이벤트 보상은 기존 `/operations/events/:id/claim`, 일반 선물은 기존 `/gifts/:id/claim`을 사용한다. 별도 지급이나 gift DB 복제를 만들지 않으므로 기존 수령 기록·App mutation 재시도 키·서버 중복 수령 방지를 유지한다. 이벤트의 기존 만료 정책을 유지하고 수령 가능 기한을 표시한다. 이미 받은/종료된/시작 전/빈 보상은 목록에서 제외한다. 수령 중에는 다른 수령 버튼도 잠가 중복 탭을 막는다. 하트가 가득 차면 기존 일반 하트 선물을 보관하고 수령 버튼을 비활성화한다. 받은 뒤 ordinary gift 목록을 갱신해 운영 보상의 초과 하트도 기존 gift 목록에서 표시할 수 있다.

기존 이벤트 페이지·보물 카드·운영 API/DB 코드는 이번 작업에서 변경하지 않았다. 제외한 네 파일의 전후 SHA가 동일하다. 새 컴포넌트는 로딩/조회 오류 재시도/지급 오류/통합 빈 상태와 영어·일본어 안내를 포함한다.

검증: 타입 검사, 기존 보상·번역10개와 알림13개 테스트, Vite production build 통과. 초기 개발 서버는 다른 파일의 HMR/삭제된 이전 모듈 참조로 검수가 불안정했고, 보상 fixture의 고정 서버 시각도 맞춰야 했다. 별도 정적 빌드에 실제 App과 격리 API를 묶어 재검수했다. `output/verification/settings-inbox-v114/browser.json`의28개 확인: 홈 아이콘 없음, 설정 행 교체, 일반/이벤트 동시 표시,300코인/복원2/귀속 망치1의 정확한 지급, 일반 망치2 지급, 오류 후 동일 idempotency key 재시도, 재개 시 받은 이벤트 재노출 없음, 가득 찬 하트 보관, 조회 오류 회복, 통합 빈 상태.320×568/390×844/430×932 및320px 영어·일본어에서 가로 넘침 없음. 브라우저 runtime error0. 실제 계정의 보상은 변경하지 않았다.
