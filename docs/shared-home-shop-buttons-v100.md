# 홈·상점 공용 버튼 통일

2026-11-23. ‘불러오는 중…’에 사용하는 기존 공용 버튼의 네모난 모서리와 금색 테두리를 홈·상점의 행동 버튼에 재사용했다.

- 홈 레벨/이어서 플레이와 정원 꾸미기의 `rasterFrame={false}` 및 별도 둥근 배경을 제거했다. 레벨은 기존 초록 `button_play`, 꾸미기는 기존 `button_gold`에 코랄 색조만 적용한다. 황금 정원의 노랑/반짝임과 상태 확인의 로딩·재연결 동작을 유지한다.
- 상점 꾸러미 보기/구매, 도구 가격, 코인 구매에 덮어씌운 둥근 배경을 제거하고 같은 공용 nine-slice를 사용한다. 상품 카드·가격·구매 로직·모달·푸터는 변경하지 않았다.
- 실제 App을 구동하는 로컬 모의 API에서390×844/320×640/430×932 한국어와320×640 영어·일본어를 확인했다. 홈2개와 상점20개 버튼의 프레임·문구가 영역 안에 들어가며, 초록 버튼은 로딩 기준 버튼과 동일한 이미지 해시를 사용한다.
- 지연 응답을 넣어 실제 ‘불러오는 중…’의 비활성 상태와 공용 프레임을 확인했다. 별도 모의 응답으로 황금 정원 버튼도 같은 프레임 규칙과 영역 안에 표시됨을 확인했다.
- 홈의 레벨 준비 모달/꾸미기 열기·닫기, 망치2개500코인 구매(8115→7615), 마지막 코인 구매 버튼 접근 및 확인·취소를 확인했다. pageErrors=[]. 실제 결제·네이티브·운영 배포 검증은 수행하지 않았다.
- `npm run build`와 변경 파일의 `git diff --check` 통과. 결과와 캡처는 `output/verification/shared-home-shop-buttons-v100/verify.json` 및 같은 폴더 PNG에 보존했다.
