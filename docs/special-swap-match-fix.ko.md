# 아이템 교환과 일반 매치 동시 처리

2026-11-03. 아이템과 일반 타일을 교환해 일반 매치를 완성한 경우, 아이템만 발동하고 매치가 낙하로 흩어지던 문제를 수정했다.

`applyAction`의 단일 아이템 교환 분기에서도 교환 직후 `findMatches`를 수행한다. 아이템 효과와 일반 매치를 동일 제거 단계에서 처리하여 색상 목표·인접 장애물·색상 화분 반응을 유지한다. 4개 이상 매치로 새 아이템을 생성할 칸은 해당 단계의 아이템 효과로부터 보호한다. 이동은 한 번만 사용하며 사용한 아이템도 한 번만 발동한다. 원래 1.0 엔진의 재생 규칙은 유지한다. 현재 1.1 서버와 클라이언트의 공통 코드를 수정하여 진행 중인 현재 버전의 판에도 다음 교환부터 적용된다.

규칙 수정으로 연쇄 결과가 달라지는 승인 맵은 배치를 바꾸지 않고 클리어 행동 기록만 다시 인증했다. `tools/level-validation/refresh-proofs.ts`는 기존 행동이 여전히 유효하면 유지하고, 필요한 경우 동일 맵에서 검증된 무구매·무섞기 해법을 갱신한다. 맵 정의 SHA-256이 바뀌지 않았음을 확인했다. 200개 중 58개 결과 해시와 48개 행동 기록이 갱신되었다.

검증:

- 회귀 17개: 5종 아이템 양방향 교환, 물방울 2×2, 가로/세로 4개, 5개, L자, 일반 3개, 서리와 원거리 색상 화분, 1.0 동작 유지.
- 전체 32파일·231검사 및 타입 검사 통과. 기존 1.0의 200개 원본 클리어 해시도 유지한다.
- 승인 200개 및 원거리 레벨 3개 클리어 기록 재검증. 별도 우선순위의 보조 봇도 200/200 클리어. 맵 모양·목표·이동 수·배치는 변경하지 않았다.
- `tools/api-special-swap-http.ts`: 실제 Worker/격리 D1에서 5종×양방향의 서버/클라이언트 상태와 이벤트 일치, 중복 요청, 한 번 이동 차감, 저장된 판, 재화 유지 확인.
- Safari에서 실제 `Board`와 실제 행동 API를 사용하는 별도 검수 계정으로 아이템을 위쪽 물방울과 드래그 교환했다. 물방울 목표 4→0, 이동 20→19, 줄바람 발동과 새 씨앗비행기 생성 확인. 검수 계정 연결에만 사용하는 토큰은 임시 `.wrangler` 페이지에 한정하고 실제 계정에는 접근하지 않았다.
- 아이폰 시뮬레이터 빌드·덮어 설치 완료. 설치된 365파일이 최종 번들과 동일하다. 계정·정원·진행 중인 판·거래 원장의 전체 데이터 해시가 설치 전후 동일하다.

자료는 `output/verification/special-swap-*`에 저장한다. 브라우저 전후 캡처는 별도 재현 보드이며, `special-swap-ios-final.png`는 실제 설치 앱이다. Android 프로젝트에는 같은 번들을 동기화했으며 원격 배포는 하지 않았다.
