# 타격과 모션 연결 v35

사용자가 제공한 로얄 매치 영상과 우리 게임의 54.58초 화면 녹화를 프레임으로 비교했습니다. 우리 게임의 녹화에는 오디오 트랙이 없어 그 영상에서 음향 품질을 비교했다고 주장하지 않습니다.

## 변경

- 일반 소멸의 실제 타일과 별도의 `pop_tile_*` 영상이 겹치던 재생을 제거했습니다. 실제 타일을 45ms 압축한 뒤 짧게 팽창·분해하고 같은 색 파편을 같은 타격 시점에 보냅니다.
- 실제 4/5/사각/L자 매치가 특수 타일을 생성하면 기존 타일 ID를 추적해 로그에 기록된 생성 위치로 모읍니다. 새 공급 타일이나 관련 없는 매치를 모으지 않습니다.
- 로켓 준비 360ms는 유지하고 발사 후 이동을 620ms에서 300ms로 줄였습니다. 이중 발광 궤적·로켓 머리·피격 타일의 시간 계산을 일치시켰고, 통과 후 뒤늦게 뜨던 별을 제거했습니다.
- 충격음과 진동은 발사 시점 대신 실제 remove/hit 접촉 로그를 기준으로 최대 4개 묶음으로 제한합니다. 일반 매치는 짧은 보드 반동, 첫 특수 피격은 중간 강도 진동을 사용합니다. 늦게 누적된 피드백은 재생하지 않습니다.
- 독자 합성한 짧은 매치/충격/장애물 소리를 사용하고 첫 충돌 전에 무음으로 미리 불러옵니다. 소리·진동 끄기 및 백그라운드 정지를 지킵니다. 샘플은 24kHz 모노, 160/250/220ms이고 클리핑이 없습니다.
- 낙하의 거리별 가속은 유지하고 착지 압축을 강화했습니다. 충격 때문에 판 전체를 멈추거나 입력 제한을 늘리는 별도 히트스톱은 넣지 않았습니다.

## 확인

`output/verification/impact-v35/`에 원본/게임 녹화 추출 프레임, 브라우저 연속 캡처, 실제 앱 검사, 음향 데이터 검사, 테스트 및 네이티브 리소스 동기화 결과를 저장했습니다. `impact-preview.mp4`는 390px 폭의 실제 브라우저 화면을 이어 붙인 무음 영상입니다. 캡처 간 실제 시간 간격을 사용했으며 인코딩의 60fps를 실기기 렌더링 60fps의 증명으로 취급하지 않습니다.

- 67개 파일 / 463개 자동 테스트, TypeScript 통과.
- 실제 App의 60레벨: 6파동 후 다시 조작, 다음 특수 타일 사용, 토끼 이동/도착 후 승리 모달, console error 0개.
- 일반 4파동과 로켓 2파동: 입력 잠금 해제, 최종 상태와 목표 유지. 원래 재생/게임 규칙이나 API 계약은 바꾸지 않았습니다.
- 운영 API 설정으로 웹 리소스 533개를 iOS·Android에 동일하게 동기화하고 Release API 검사 통과. 기존 프로젝트 버전인 iOS 1.06(7), Android 1.05(6)는 변경하지 않았습니다.
- 서버 코드 변경·배포, Archive, APK 제작, 스토어 업로드는 이번 작업에서 수행하지 않았습니다.

실물 Android/iOS에서 진동의 체감 세기, 스피커/무음 모드와 프레임 안정성은 아직 확인하지 않았습니다.
