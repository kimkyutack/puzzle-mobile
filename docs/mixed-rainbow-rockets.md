# 무지개등·로켓 조합의 혼합 방향

로켓과 무지개등을 합치면 가로·세로 로켓이 섞여 생성된다. 입력 로켓의 방향과 관계없이 적용하며 강화 무지개등도 같은 규칙을 사용한다. 변환할 타일이 두 개 이상이면 두 방향을 반드시 포함하고 개수 차이는 최대 한 개다. 배치는 시드 기반으로 섞어 클라이언트와 서버가 동일하게 재생한다. 한 타일만 변환할 때도 정상 발동한다.

## 변경

- 엔진 1.35.0에서 혼합 방향을 활성화한다. 이전 엔진 버전을 지원 목록에 보존하고 1.34 이하 진행 중인 판의 기존 조합 결과를 유지한다.
- `rainbowSelections`가 각 변환 위치의 실제 아이템 종류를 읽는다. 반대 방향 로켓도 해당 조합의 자식 발동으로 묶고 변환·대기·발사 순서를 동일하게 처리한다.
- 변환 중 보이는 로켓 스프라이트도 위치별 실제 종류를 사용해 그림과 피해 방향을 일치시킨다.
- 같은 장애물에 조합 한 번당 한 번만 피해를 주는 기존 로켓/폭탄 규칙은 유지한다.
- 기존 장애물 판의 저장된 인증 로그는 원래의 1.34 규칙으로 검증하도록 명시했다. 새로운 규칙의 플레이 가능 여부는 별도로 자동 플레이했다.

## 검증

- 관련 17파일 231테스트 통과. 일반/강화·로켓 두 방향·양쪽 교환 순서, 1~2개 변환, 여러 시드, 서버/클라이언트 재생 및 이펙트 타이밍, 기존 엔진 복구를 포함한다.
- `npm run build` 통과. 기존 큰 번들 경고만 있다.
- 실제 `CascadeBoard`와 이펙트를 브라우저에서 네 조합으로 실행했다. 일반 무지개등은 가로 7/세로 6개, 강화는 가로 14/세로 14개로 변환·발사되는 것을 확인했다. 입력 로켓이 가로든 세로든 동일하다. 최종 `pageErrors: []`.
- 공성·후속 공성·선반/차양/원정·이동 장애물의 총 99개 프로필을 새로운 엔진으로 자동 클리어했다. 시드는 그대로 유지하고 기존 인증 이동 수+3(도입판은 기존 여유)을 사용했다. 구매 아이템과 셔플 없이 확인했으며 사람의 승률을 의미하지 않는다.
- 근거와 재현 코드: `output/verification/mixed-rainbow-rockets/`. 브라우저 캡처: `output/playwright/mixed-rockets-{row,column}-{normal,powered}.png`.

현재 소스 수정과 로컬 검증 완료 상태다. 운영 배포와 iOS/Android 네이티브 동기화는 수행하지 않았다. 새로운 규칙은 업데이트된 서버와 앱이 1.35를 협상해 시작하는 새 판에 적용된다.
