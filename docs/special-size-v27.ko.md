# 보드 특수 아이템 크기 · v27

2026-11-05. 사용자 화면에서 가로·세로 폭탄과 무지개등 등이 일반 블록보다 작게 보이는 점을 보정했다.

`tile-visuals.ts`가 일반 블록은 기존 셀 배율 0.99를 유지하고, 가로·세로 폭탄·꽃폭탄·비행기·무지개등의 PNG 캔버스 배율만 1.18로 적용한다. 투명 여백을 포함하던 동일 캔버스 기준을 보정한 것으로, 실제 그림은 약 19.2% 커지고 긴 축이 셀의 약 96~97%를 차지한다. 원화 비율·색상·타일 간격·보드 크기·선택 범위·게임 규칙은 유지한다. PNG 원본을 덮어쓰거나 가로·세로 비율을 늘이지 않는다.

같은 보정 비율을 아이템 부상·합성·선형 발사·비행기 비행과 운반·무지개등 충전에 적용했다. 정지 그림만 커지고 발동 직후 원래 크기로 줄어드는 차이를 줄였다. 기존 연출 시간과 파티클 상한은 그대로다.

실제 9칸 보드를 390×844와 320×740에서 확인했다. 네 모서리와 아래 행에 특수 아이템을 배치해 그림이 셀 안에 머물고 수평 넘침이 없는 것을 확인했다. 런타임 PNG의 실제 알파 경계로 계산한 두 화면의 12개 크기/경계 검사는 `output/verification/special-size-v27/visible-bounds.json`에 있다. 일반 빨강 블록의 전후 크기는 같다.

모션·연출 타이밍·합성·타일 이동·보드 경계 관련 5파일 26검사와 타입 검사, `npm run native:release`가 통과했다. iOS/Android의 웹 리소스 동기화까지 완료했으며, 실제 설치본은 다시 빌드·설치해야 반영된다. Worker나 운영 DB 변경은 없다. 브라우저 캡처와 빌드/동기화 증거는 `output/verification/special-size-v27/`에 보관한다.
