## 발견과 수정 이력

1. **P1 — 공통 CSS가 홈 전용 높이를 덮어씀.** 이전 내비게이션 부모는98px, 안쪽 푸터는93px였다. 푸터가 시안보다5px 위에 나타나고 버튼/아이콘 행도 함께 어긋났다. 홈 전용 선택자의 우선순위와 높이 토큰을 정리했다. 최종 부모와 푸터 모두 y751/h93/bottom844다.
2. **P2 — 두 아이보리 패널의 아래쪽 둥근 모서리.** 패널 사이로 정원이 비치는 틈과 별도 알약 모양이 생겼다. 위 모서리만 둥글게 유지하고 배경을 연결했다. 시안의 빈 배경 가장자리에서 추출한 아이보리 재질을 사용한다.
3. **P1 — 도구 축제 프레임의 투명 테두리.** `FrameFace`의 인라인 border-width가 남아 배경이 안으로 밀리며 네모나게 보였다. 홈 범위에서 border와 border-image를 함께 해제했다. 축제 캡슐은 x292/y545/w92/h40이며 실제 계산된 테두리는0px다.
4. **P2 — 도구 축제 아이콘에 붙은 배경과 글자 조각.** 기존 크롭에 파란 프레임과 인접 글자 일부가 들어 있었다. 원본에서 상자 영역을 다시 분리하고 연결된 배경 픽셀을 매팅했다. 연승 선물 아이콘도 원본에서 분리했다.
5. **P2 — 홈 탭 표면 윗부분의 수평 절단.** 중앙 배경 조각이 모서리 픽셀과 맞지 않았다. 원본 외곽선은 유지하면서 내부 그림·글자만 깨끗한 옆 재질로 비운 새 표면을 사용했다.
6. **P2 — 레벨 글꼴과 버튼 폭.** 축약한 선택자가 기존 Lilita One 선언을 이기지 못했다. Jua가 적용되는 선택자로 수정하고 원본의193px/174px 버튼 및5px 간격을 복원했다. 레벨 글자의 흰색 픽셀 경계는 시안과 구현 모두 x48..145/y689..711이다.
7. **P2 — 선물/푸터 타이포그래피와 여백.** 선물 이름·단계의 굵기/색, 로고 크기, 숫자 캡슐, 푸터 글자 크기·행간·아이콘의 투명 여백을 보정했다. 선물 캡슐은 x7/y547/w222/h36이다. 실제 게임 아이템은 교체하지 않았다.
8. **P2 — 홈의 큰 새 이벤트 띠.** 아이콘 위로 돌출된 띠가 시안의 푸터 실루엣을 바꿨다. 홈에서는 기존 RewardDot으로 새 이벤트를 표시하며 다른 탭의 기존 띠 표시와 알림 의미는 유지한다.

첫 비교는 `before-layout.json`과 `home-v80-before.png`에서 확인했다. 1차 수정의 `comparison-pass1.png`에서 프레임 내부의 잔여 픽셀과 글꼴 우선순위 문제를 발견해 수정했다. 2차 `comparison-pass2-*`에서 재질의 수평 줄과 딱딱한 그림자를 발견해 깨끗한 원본 열 샘플 및 배경을 분리한 부드러운 그림자로 교체했다. 3차 `comparison-pass3-*` 및 최종 전체/확대 비교에서 다시 확인했다.

## 필수 표면 대조

- **글꼴:** 기존 Jua/Lilita 리소스를 유지하고 레벨·단계·선물 제목·푸터의 실제 적용 글꼴과 굵기를 확인했다. 임의 폰트 파일은 추가하지 않았다. 작은 화면의 한·영·일 문구가 실제 버튼 경계를 넘지 않는다.
- **배치:** 동일한390×844 화면에서 캡슐·메뉴·버튼·푸터를 재촬영했다. 부모/자식 높이, 간격, 모서리와 그림자까지 확인했다.
- **색:** 버튼과 캡슐은 원본 재질, 아이보리 패널은 원본 빈 배경 샘플을 사용한다. 단계 숫자의 따뜻한 잉크색과 단계 배경도 보정했다.
- **이미지:** 원본에서 추출한9개 작은 raster 자산을 사용한다. 앞선 크롭의 배경/글자 오염을 제거했으며, 새 그림이나 아이콘 대체물을 생성하지 않았다. 원본 크롭·좌표·재현 스크립트를 보존했다.
- **내용:** 라벨과 실제 알림·연승·게임 아이템·축제 시간은 기존 모델을 따른다. 시안의 예시 숫자를 강제로 넣지 않았다.

전체 비교: `comparison-full.png`. 확대 비교: `comparison-dock.png`, `comparison-chips.png`, `comparison-footer.png`, `comparison-buttons.png` (모두 `output/verification/home-fidelity-v80/`). 원본과 구현을 같은 이미지 안에 넣고 확인했다.
