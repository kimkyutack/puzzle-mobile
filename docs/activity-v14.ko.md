# 정원 활동 확장 v14

## 이용 흐름

- 홈의 미션 버튼에서 일일 7개, 주간 10개 미션과 보상을 확인한다. 일일은 한국 시간 자정, 주간은 월요일 자정에 갱신된다. 타일 수집·특수 타일 생성/사용·조합·난이도별 클리어·미니게임·방문 일수를 서버의 실제 기록으로 집계한다.
- 보물 카드는 12장의 카드에서 6쌍을 찾는 별도 미니게임이다. 하루 3회, 한 판 12번 도전하며 하트를 사용하지 않는다. 성공하면 25코인과 도구 1개를 받는다. 뒤집기와 판정은 로컬에서 실행하고, 종료 시 행동 기록을 서버에서 검증한다. 진행 중 카드는 기기에 보관하여 다시 열 수 있다.
- 새 퍼즐 10판을 완료할 때마다 별빛 대폭탄 1개를 자동 지급한다. 실패·포기·중복 완료는 누적되지 않는다. 기존 `level_rewards`에 검증된 클리어도 합산하고, 이미 지급한 구간은 다시 지급하지 않는다. 이 아이템은 상점에서 팔지 않는다.
- 추가 도구는 십자 폭죽(가로·세로 동시 타격, 350코인), 색상 자석(선택한 일반 타일의 색 수집, 400코인), 모래시계(이동 +3, 300코인)다. 인게임 하단은 빠른 도구 4개와 도구 가방, 설정으로 유지한다. 새 아이템과 테두리 폭죽은 가방에서 선택한다.
- 미션·이벤트·패스·선물함의 받을 수 있는 보상과 친구 신청·길드 승인 요청에 빨간점을 표시한다. 해당 메뉴와 상위 홈/푸터로 집계하며, 수령·처리 후 제거한다. 잠긴 프리미엄 보상과 구매 가능한 유료 상품은 수령 알림에 넣지 않는다.

## 레벨과 호환

31~200레벨은 보석 수집, 얼음 계단, 분리 수로, 고리 정원, 씨앗 배달, 색상 화분, 이끼 추격, 씨앗 저장고, 덩굴 협곡, 다층 상자, 얼어붙은 온실, 특수 조합 축제 등 12개 공략 유형을 사용한다. 조합·특수 타일 사용을 실제 클리어 목표로 추가했다. 기존 첫 30개 학습 배치는 유지한다. 일반/어려움/매우 어려움은 색 수·층수·목표 수·이동 여유를 함께 조정한다.

새 엔진은 1.2다. 1.1 콘텐츠·승리 기록은 `legacy-approved-v11.json`, `legacy-solutions-v11.json`으로 보존했고, 1.0도 유지한다. 기존 진행 중인 판의 씨드·상태·목표를 변경하지 않는다. 구버전 클라이언트의 새 판 요청은 해당 버전의 고정 콘텐츠로 응답한다.

200판 모두 아이템 구매 없는 승리 행동 기록을 재생 검증했다. 이는 풀이 가능성 검사이며 사람의 체감 난이도/승률 검증은 별도다. 결과: `output/verification/expanded-levels-v14.json`.

## API·저장

- `GET /progression`: 현재 기간 미션, 전체 폭탄 누적, 미니게임 남은 횟수, 메뉴별 알림 수. 최초 방문/누락된 누적 보상만 원자적으로 보완한다.
- `POST /missions/claim`: `key,period,periodId,ids?`. ids 생략 시 현재 수령 가능한 미션 모두 받기. 기간이 바뀐 요청은 거절한다.
- `POST /minigames/treasure/start`: `key`. 기존 진행 중인 판이 있으면 재개한다.
- `POST /minigames/treasure/:id/finish`: `key,pairs:[{first,second}]`. 성공/실패만 종료 가능하며, 짝 재사용·위조된 완료·타인의 판·횟수 초과는 거절한다.
- 새 도구도 기존 로컬 행동 큐와 `/runs/:id/actions` 원자적 검증/아이템 차감을 사용한다. 유료 +5 이어하기와 최종 보상은 서버 확인을 유지한다.
- D1 migration `0011_activity_and_treasure.sql`. 계정 삭제 시 새 활동·미니게임 개인 기록도 제거한다.

보상은 기존 Player 버전 CAS와 [D1 batch 트랜잭션](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch) 안에서 기록과 함께 반영한다. 재시도/동시 요청은 중복 지급하지 않는다.
