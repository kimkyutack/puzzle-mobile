# 젤리 블록 타일과 9열 기준 크기

일반 타일 6종을 살짝 둥근 네모 블록으로 통일했다. 빨강·파랑·노랑·초록·보라·주황의 진한 색상, 부드러운 볼륨, 가장자리의 은은한 젤리 질감으로 구분한다. 밝고 선명한 색면과 얇은 베벨을 사용하며, 넓은 흰 반사광과 외부 발광은 넣지 않는다. 타일 몸체는 칸 너비의 약 79~82%, 높이의 약 85%를 차지하여 가로·세로에 바닥이 보이는 간격을 둔다. 개별 원본은 `packages/assets/source/tile_block_*_v15.png`, 내장 image_gen의 정확한 프롬프트와 출처는 `packages/assets/tile-set-v15.json`에 있다.

보드의 타일 간격은 사용 가능한 폭에서 9열이 들어가는 크기를 기준으로 계산한다. 7열·8열 맵은 같은 간격을 쓰면서 가운데 놓인다. 7열 타일은 종전 대비 약 22%, 8열은 약 11% 작아진다. 프레임 여백을 별도로 계산하여 열 수에 따라 타일 간격이 달라지지 않게 했다. 터치 좌표는 축소된 캔버스의 실제 너비를 기준으로 변환한다.

목표, 접근성 이름, 튜토리얼, 길드 문장 선택, 보물 카드, 타일 파편 효과도 같은 이미지와 색 이름을 쓴다. 서버에서 보내는 기존 미션 이름은 화면에서 현재 블록 이름으로 표시한다. 저장된 퍼즐의 색 식별자와 서버 판정은 유지한다.

런타임 이미지 팩: `garden-2026.11.04-jelly-v15`. 여섯 타일은 각각 생성한 독립 원본이며 기존 자산 파이프라인에서 알파 잔여물 제거와 크기 정규화 후 아틀라스로 묶는다. 단일 블록만 분리된 잔여물을 모두 제거하고, 다른 아이콘의 분리된 장식은 기존 방식으로 보존한다.

검수 화면: `tools/tile-scale-v15-fixture.html`, `tools/tile-scale-v15-harness.tsx`. 실제 Board 컴포넌트와 로컬 퍼즐 엔진을 사용하며 계정·인벤토리·API 요청을 사용하지 않는다.
