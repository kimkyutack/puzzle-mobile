# 꽃빛축제와 동물 구출 원정

## 플레이 흐름

- 꽃빛축제는 레벨 10부터 이벤트 페이지에 표시한다. 무료 참여 버튼을 누른 서버 시각부터 개인별 7일 동안 진행한다. 첫 행사 ID는 `flowerlight-invitation-v1`이며 반복 초기화하지 않는다.
- 참여 이후 시작한 **새 일반 레벨**의 첫 클리어마다 꽃잎 1개를 적립한다. 원정·재클리어·참여 전에 시작한 판·기한 이후에 확정한 판은 적립하지 않는다. 실패해도 진행도를 차감하지 않는다.
- 누적 꽃잎 2/5/9/14/20개로 입구/꽃길/분수/손님/개막을 차례로 복원한다. 누적 목표이며 꽃잎을 중복 차감하지 않는다.
- 도입, 분수 복원, 마지막 개막에 짧은 이야기가 나온다. 장면에 실제 시설·동물·조명이 추가된다.
- 모든 단계는 코인과 도구를 준다. 마지막에는 행사 전용 `garden-flowerlight-fountain`을 정원 보관함에 지급한다. 설치 위치를 강제로 바꾸지 않으며, ‘정원에 놓기’는 꾸미기의 보관함을 바로 연다. 분수는 앞/뒤 래스터와 반전으로 네 방향 배치를 지원한다.
- 기간이 끝나면 수집은 정지한다. 이미 달성한 단계의 복원과 보상 수령, 완성한 장면 보기는 계속 가능하다.

## 동물 구출 원정

- **플레이어의 다음 레벨이 20에 도달하면 표시하고 해금한다.** 레벨 19 이하에서는 입구 카드가 보이지 않고, 서버에서도 시작/보상 요청을 거부한다.
- 첫 원정은 꽃귀 토끼의 귀갓길을 여는 다섯 코스다. 일반 캠페인과 독립된 진행이며 일반 레벨/별/패스 점수를 올리지 않는다.
- 코스마다 일반 레벨과 별개인 길 구조와 검증된 세 가지 초기 배치를 사용한다. 명시적 재도전마다 다음 배치로 바뀐다. 총 15개 배치의 구매 도구 없는 승리 기록을 `animal-expedition-proofs.json`에 보관한다.
- 하트와 보유 도구를 소모하지 않는다. 실패하면 현재 코스만 무료로 재도전한다. 완료한 코스와 보상은 유지한다.
- 보드와 연쇄 애니메이션은 기존 로컬 엔진과 `CascadeBoard`를 사용한다. 시작/다시 시작/완료 검증 시에만 API 요청하며, 매 이동을 서버로 보내지 않는다.
- 진행 중 행동 기록은 계정·시도 ID 별로 기기에 저장한다. 돌아오면 서버의 초기 맵과 기록으로 재생한다. 다른 기기에서는 같은 시도의 초기 맵으로 시작하며, 완료된 코스는 서버에서 이어진다.
- 서버가 지정한 맵에서 교환/탭 행동만 재생하여 승리를 검증한다. 클라이언트의 승리 상태, 이동 수, 보상 수량은 신뢰하지 않는다.
- 코스별 선물과 마지막 꽃귀 토끼는 한 번만 지급한다. 토끼는 보관함에서 설치하면 기존 산책/휴식 행동을 사용한다.

## 서버와 운영

| API | 역할 |
| --- | --- |
| POST `/flowerlight/start` | 개인 7일 행사 시작. 기존 행사 초기화 불가 |
| POST `/flowerlight/restore` | 다음 단계 목표 검증 및 보상 |
| POST `/animal-expedition/start` | 서버가 다음 코스 시도 발급/복구. 명시적 재도전 시 교체 |
| POST `/animal-expedition/finish` | 행동 재생 및 코스 보상 확정 |

새 앱의 정원 요청은 `gardenArt=flowerlight-v42` 능력값을 보낸다. 이전 앱에는 새 분수를 같은 3×3 크기의 기존 분수로 표시한다. 이 처리는 응답 그림 정보에만 적용하며 원본 장식 ID·지급 내역·정원 revision을 바꾸지 않는다.

진행은 기존 플레이어 JSON에 선택 필드로 보관하므로 스키마 마이그레이션이 필요 없다. 기존 앱/저장된 일반 퍼즐의 엔진 규칙은 변경하지 않는다. 꽃잎은 일반 클리어 보상과 같은 트랜잭션에서 갱신해 이동당 DB 왕복을 추가하지 않는다.

분수/토끼의 정원 지급과 코인/도구/진행 갱신은 플레이어 버전, 정원 revision, 요청 멱등키와 함께 커밋한다. 정원 저장에 실패하면 진행과 보상도 롤백한다. D1의 batch 트랜잭션 계약은 [공식 문서](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)를 따른다.

운영 콘솔 ‘기능·가격’에서 꽃빛축제와 동물 구출 원정을 각각 일시 중지할 수 있다. 기존 저장 설정에는 새 스위치만 기본 활성화 값으로 보완하고 다른 점검/버전/가격 설정을 유지한다.

행사 시작 수·단계 도달·코스 완료는 기존 `operations`의 fingerprint(`flowerlight:start`, `flowerlight:restore:*`, `animal-expedition:start:*`, `animal-expedition:finish:*`)로 집계할 수 있다. 중복 키의 재요청은 기존 응답을 반환하므로 중복 집계를 피할 수 있다. 사람의 완주율/재방문율은 출시 후 별도로 측정해야 한다.
