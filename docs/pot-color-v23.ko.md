# 색상 화분 요구 타일 표시

2026-11-04. 색상 화분의 왼쪽 아래에 `obstacle.color`에 해당하는 기존 일반 타일 PNG를 표시한다. 오른쪽 아래의 남은 횟수와 구분하며, 타일/장애물/이동 연출보다 위에 있는 기존 카운터 레이어를 사용한다. 요구 아이콘은 칸 크기의 44%이며 칸 안에 들어간다.

HP 갱신 시 아이콘을 함께 갱신하고, 화분 제거 시 함께 제거한다. 한 번 남은 상태에서도 아이콘은 유지된다. 최초 등장 안내의 한국어·영어 문구에도 아이콘 위치와 보드 어디서든 지정 색을 맞추는 규칙을 명시했다. 원화·충전 규칙·퍼즐 상태·API는 변경하지 않는다.

`tools/pot-color-v23-fixture.html`은 실제 Board를 사용하는 계정/API 없는 시각 검수 화면이다. 6색 샘플과 실제 18/36레벨, 마지막 1회 및 제거를 확인할 수 있다. 1~10,000레벨의 화분 색을 조회했으며 현재 6색 모두 사용한다.

검증: 타입 검사, 기존 impact-overlay/feature-help 8검사, CUA 390px 6색 및 320px 실제 36레벨(파랑·노랑) 표시, 1회 남은 상태의 유지와 제거 후 정리. iOS/Android 웹 리소스 동기화와 실제 설치본 갱신은 구분한다. 증거는 `output/verification/pot-color-v23/`에 보관한다. 이번 변경은 클라이언트 표시만 수정하므로 Worker 배포는 필요하지 않다.
