final result: passed (아래 로컬 웹 범위)

## 반영 내용

- 도구 축제 시간 칩을 본문 상단 중앙(제거한 제목 위치)으로 이동. 시즌 칩도 하늘 위쪽으로 이동하고 배경의 기존 시계 영역을 제거해 중복 없이 표시.
- 아이템 무제한의 온실/모래시계 원화와 실제 도구 세 개, 운영 설정의 시간표, 카운트다운, 실제 게임 버튼을 조합. 후속 요청에 따라 이벤트 탭과 홈 하단 배너에서 제거하고 홈 우측 바로가기 + 닫을 수 있는 모달로 변경.
- 홈 칩: 활성화 시 노란 둥근 칩 ‘남은 시간’, 대기 시 파란 판형 칩 ‘시작까지’. 서버 보정 시각과 기존 KST 일정 계산을 사용하며 초 단위 표시는 로컬 타이머이고 추가 API polling은 없음. 비활성/유효한 일정 없음이면 바로가기를 숨김. 기존 시간 이벤트의 서버 적용 규칙 변경 없음.
- 이벤트 보상은 우편함/목재 배경과 실제 보상 엽서/파란 수령 합계판. 운영 데이터의 보상과 기간을 표시하며 단건/모두 받기는 기존 지급 API를 순차 호출. 성공한 건만 수령 상태를 갱신하고 중간 실패는 재시도 시 건너뛰도록 보존. 합계는 활성 목록의 수령 완료 합계이며, 청구 시각을 알 수 없으므로 ‘오늘’이라고 표시하지 않음.
- 보상 카드 모서리와 날짜/무제한 일정 글자 대비를 재보정. 기존 게임의 코인·복원·아이템 원화와 게임 버튼 유지.

## 브라우저 검수

Chrome 실제 브라우저에서 production 빌드 CSS와 실제 React 컴포넌트를 사용한 로컬 전용 fixture로 확인했다. fixture의 API/계정/시각은 합성이며 실제 사용자 데이터를 변경하지 않는다.

- 도구/시즌 시간 칩의 중심/상단 좌표 및 중복 시계 없음 확인. `tools-timer-402.jpg`, `season-timer-402.jpg`.
- 402×874 한국어 홈의 활성 칩(09:xx), 클릭 후 모달 표시, 닫기 후 dialog 수 0, 재개방 후 퍼즐 버튼이 레벨 시작 경로로 이동하는 것 확인. fixture의 레벨 시작 도착 표시이며 실운영 퍼즐 개시는 이번 UI 검수 범위에 포함하지 않음.
- 320×694 영어 홈의 대기 칩(4:59:xx), 대기 모달의 시간표·도구·게임 버튼 확인. 모달 294.4×433.9, 본문 client/scroll 434/434, 문서 가로 client/scroll 320/320, 모달 이미지 누락 0.
- 320×694 한국어에서 패키지 2개와 무제한·주간 이벤트·선물함이 동시에 있는 경우 검수. 첫 구현에서 선물함이 보상판에 가려져 아이콘이 많은 소형 화면의 우측 패널을 보정. 최종 선물함 bottom 419, 보상판 top 441.22로 간격 확보.
- 홈의 이벤트 버튼으로 실제 탭 목록에 진입해 출석/꽃빛/보물/도구/시즌/보상만 있고 아이템 무제한 탭은 없는 것을 확인.
- 보상 3개 fixture에서 개별 수령→모두 받기 후 코인 500/복원 5/망치 1/로켓 3 집계와 비활성 버튼 확인. 320px 영어 단건 및 402px 한국어 최종 파란 합계판도 직접 캡처/검토. 활성 보상 0개면 기존 정책에 따라 탭 자체가 숨겨지므로 empty 화면 캡처를 증거로 사용하지 않음.
- 최종 탭의 신규 console error/warning 0. 임시 뷰포트 해제 완료.
