## 변경

- `HubNavigation`이 모든 탭에서 같은 `command-navigation` 구조와 배경을 사용한다. 이전 파란 footer frame과 다른 선택 frame을 제거했다.
- 선택한 탭의 중심에 흰 상승 곡선과 파란 배경이 함께 놓인다. 실제 탭 개수와5px 간격,8px 좌우 여백을 기준으로 중심을 계산한다.
- 원본 아이콘별 크기/광학 보정을 메뉴 의미를 나타내는 `data-hub-tab` 기준으로 적용해, 일부 탭이 없는 환경에서도 다른 아이콘 규칙이 잘못 적용되지 않는다.
- 큰 '새 이벤트' 띠 대신 홈과 동일한 빨간 알림 점으로 기존 알림과 새 이벤트 상태를 표시한다. 이벤트 방문 확인과 실제 알림 개수 로직은 유지한다.
- 페이지가 새 푸터의 실제 높이에서 끝나도록 하단 inset만 맞췄다.390×844에서는 푸터y751/h93, 작은 화면은 기존68px+safe bottom 높이를 사용한다.

첫 확인에서 원래 홈 배경색이 rim 바깥 픽셀에 남아 진한 본문 배경에서 거칠게 보였다. 원본 rim과 내부 면은 유지하면서 외부 배경색을 alpha로 분리했다. `packages/assets/shared-footer-v88/extraction.json`, `tools/asset-pipeline/shared-footer-v88.mjs`에 재현 방법을 보존했다. 원본v81/v82 자산은 덮어쓰지 않았다.

3개 메뉴 상태를 확인했을 때 기존 grid의 열 수와 실제 표시 메뉴 개수가 달랐다. 3열 배치를 명시해 아이콘 중심과 곡선 중심을 맞춘 뒤 전체 검증을 반복했다. 최종 검증의3개 탭 중심은 각각68.656px/321.328px이며 대응하는 곡선과0.001px 이내에서 일치한다.
