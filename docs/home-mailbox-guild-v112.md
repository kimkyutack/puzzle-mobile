# 홈 선물함·길드 정보 가독성 v112

## 변경

- 홈의 기존 떠 있는 봉투 버튼을 제거했다. 원본 파란 우체통/선물 꾸러미 raster를 제작해 `home-icon-art.ts`의 기존 아이콘 등록 방식으로 연결했다. 기록 봉투 및 다른 메뉴 원본은 유지한다.
- 선물함 버튼은 접히는 extras 바깥, 고정 dock의 왼쪽 상단에 배치한다. 패널과 함께 이동하고 접힘/펼침 및 전환 중에도 가려지지 않는다. 기존 `onMenu('gifts')`, 접근성 이름, 알림 점을 유지한다. 정원 카메라 inset 계산도 새 버튼의 상단을 포함한다.
- 길드 배너에는 문장/이름/지도 그림을 유지하고, 소개와 인원·최소 레벨을 지도 아래 별도 sky-blue 정보칸에 둔다. 정보칸은 그림의 뒤가 아닌 별도 흐름에 있으므로 배경과 겹치지 않는다. 긴 이름은 캐릭터 위 공간을 추가 확보한다. 소개는 기존 전체 DOM/title을 유지하며2줄 표시한다.

## 범위

`HomeHub.tsx`, `home-icon-art.ts`, 새 `home-mailbox-v112.css`, `CommunityMenus.tsx`, `guild-map-v109.css`, 새 원화 자산만 이번 작업으로 변경했다. 기존 푸터·선물함 모달·보상 계약·길드 API는 그대로다. 보물 카드 두 파일은 전후 SHA가 동일하다. 계정/길드에 운영 데이터를 기록하지 않았다.

## 검수

`output/verification/home-mailbox-guild-v112/app.html`은 실제 App에 격리 모의 API를 연결한다.

- 320×568,390×844,430×932에서 접힘/펼침/전환100ms 지점에 `elementFromPoint`로 실제 선물함 터치 노출을 확인했다. 화살표·헤더와 겹치지 않고 기존 우측 봉투가 제거됐다.
- 실제 선물함 dialog 열기/닫기, 알림 점 유지 및 기록과 서로 다른 이미지 URL을 확인했다.
- 일반 멤버/관리자,320px 긴 길드명·소개, 빈 소개에서 정보칸이 지도 아래/탭 위에 있으며 가려짐과 가로 넘침이 없는지 확인했다. 기존 길드 대화 전송도 확인했다.
- 320px 영어/일본어의 펼친 패널도 확인했다. 브라우저 runtime error0. 마지막 긴 이름 캐릭터 간격은 `final-long.log`로 재검수했다.
- TypeScript 검사, Vite production build, 변경 파일 공백 검사 통과. 운영 배포·실기기 네이티브 검수/동기화는 이번 범위가 아니다.

원본/프롬프트: `packages/assets/home-mailbox-v112/source/`. Runtime192×192 true-alpha WebP를 사용한다. 전체 결과는 `changes.png`, 기능/배치 체크는 `browser.json`에 보존했다.
