# 시작 모달 목표 영역 넘침 수정

레벨 17의 목표 4개가 고정 간격의 한 줄 flex에 들어가면서 카드 밖으로 나갔다. StartLevelModal에 목표 수를 표시하고, 기존 프레임 안의 목표 목록을 CSS grid로 바꿨다.

- 목표 1개: 한 칸.
- 목표 2개: 2열 한 줄, 아이콘 옆 숫자.
- 목표 3개: 3열 한 줄, 아이콘 아래 숫자.
- 목표 4개: 2×2, 아이콘 옆 숫자를 유지해 높이를 줄인다.
- 목표 5개 이상: 최대 3열로 줄을 늘린다. 카드 높이는 내용에 맞춰 늘어난다.

카드·이미지·아이템 선택·시작 흐름·퍼즐 데이터는 유지했다. 작업 중이던 캠페인/공개 레벨 제한 분기도 보존했다.

## 확인

실제 StartLevelModal과 승인된 레벨 데이터를 렌더링하는 API 없는 로컬 화면에서 7개 경우를 검사했다. 현재 공개 300개 레벨의 목표 수는 최대 4개다.

| 화면 | 레벨 | 목표 |
| --- | --- | --- |
| 320×640 | 17 | 4 |
| 320×740 | 1 / 3 / 10 / 17 | 1 / 2 / 3 / 4 |
| 390×844 | 17 | 4 |
| 430×932 | 17 | 4 |

각 경우의 아이콘·숫자·항목이 목표 카드 안에 들어오고, 목록·모달·문서에 가로 넘침이 없는 것을 실제 DOM 좌표로 확인했다. 짧은 320×640 화면에서도 모달 내부 스크롤로 플레이 버튼과 하트 안내에 도달한다. 320px 인게임 목표 4개도 기존 트레이 안에 들어오는 것을 확인했다. 인게임 HUD 스타일은 변경하지 않았다.

타입 검사와 프로덕션 웹 빌드 통과. iOS/Android 웹 리소스 동기화 완료이며 설치 앱에는 재빌드가 필요하다.
