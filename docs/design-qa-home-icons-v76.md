## 발견과 수정 이력

1. **P1: 다른 아이콘을 재사용함.** 편지·상점·친구·무제한·판다 등의 실루엣과 소품이 선택 시안과 달랐다. 투명 래스터16종을 새로 제작하고 실제 Icon URL에 연결했다. 원본/구현 확대 비교에서 편지의 새싹, 줄무늬 상점, 루미 상반신, 금색 무한대 메달, 판다 얼굴, 문 형태 온실을 확인했다.
2. **P2: 작은 메뉴 글자와 주 버튼의 표현 차이.** 기존 캡션이 작고 가늘었고 재생 화살표가 없었다. 캡션 크기/자간/윤곽선, 주 버튼의 흰 글자/어두운 외곽선/깊이 그림자를 조정하고 실제 래스터 화살표를 추가했다. 활성 홈 라벨의 흰색을 덮던 CSS 우선순위도 수정했다.
3. **P2: 작은 화면과 번역 줄바꿈.** 320px 재생 화살표가 다음 줄로 밀리고 긴 영문 패키지 시간/행사 이름이 겹쳤다. nowrap·좁은 화면 글자 크기·작은 연승 캡슐의 2행 배치를 적용했다. 패키지와 행사는 짧은 한·영·일 캡션을 쓰고 전체 이름은 접근성 라벨에 유지한다. 영문 패키지 날짜는 `10d 23:59`로 표시한다.
4. 최종 전체/확대 비교와 4개 뷰포트·언어 캡처를 다시 열어 확인했다. 위 P1/P2는 해결했으며 현재 범위에 남은 P0/P1/P2는 없다.

## 필수 표면 확인

- **글자:** 기존 Jua와 Lilita One을 사용한다. 이미지 시안에는 실제 폰트 파일/메타데이터가 없으므로 동일 원본 글꼴이라고 주장하지 않는다. 글리프의 둥근 형태와 굵기, 실제 보이는 크기, 행간과 윤곽선을 시안과 대조했다. 390px에서 메뉴14px/16px, 하단14.5px/18px, 선택 홈17px/20px, 레벨28px/32px, 꾸미기19px/24px. 320px에서는 메뉴11px/13px, 레벨22px/26px, 꾸미기16px/20px로 조정한다. 원본에 없는 임의 폰트 파일은 추가하지 않았다.
- **배치:** 메뉴 슬롯48px(짧은 화면42px), 무한대38px, 판다40px, 하단46px, 선택 홈50px. 투명 여백까지 포함한 실제 실루엣을 원본과 비교했다. 타이머는 아이콘 행 크기를 늘리지 않는 absolute 표시다. 메뉴 터치 폭44px 이상, 페이지/메뉴 가로 넘침 없음, 주 버튼 한 줄 유지.
- **색:** 짙은 남색 캡션, 흰 주 버튼 글자와 녹색/코랄 외곽선, 흰 활성 홈 글자, 기존 아이보리·라임·코랄 화면 색을 확인했다.
- **이미지:**16개 모두128×128 알파 WebP, 합계220,552바이트. 새 원화와 정확한 프롬프트를 `packages/assets/home-icons-v76/`에 보존했다. 런타임은 `runtime/`이며 코드 도형·이모지·SVG 대용 아이콘을 사용하지 않았다. 기본 루미 외의 사용자 선택 아바타와 커스텀 프로필 이미지는 기존 렌더 경로를 유지한다. 다음 원정의 동물이나 다른 주간 게임을 판다로 강제하지 않는다.
- **내용:** 실제 잠금/시간/캠페인/알림/주간 로테이션/연승 아이템을 유지한다. 홈의 무지개 보주만 교체했으며 게임 파워 아이템 아트를 교체하지 않는다.
