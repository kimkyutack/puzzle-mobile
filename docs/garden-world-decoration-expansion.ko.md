# 장식과 동물 체험 상점

2026-11-04 후속: 실제 홈에는 동물 산책·휴식과 방문객, 수량 구매·연속 배치를 추가했다. 현재 범위와 검증은 [정원 산책과 여러 개 꾸미기](garden-life-and-brush.ko.md)를 참고한다. 아래는 최초 체험 상점 단계의 기록이다.

2026-11-03. 독립 정원 미리보기(http://127.0.0.1:5192/)에 새 장식6종과 동물3종을 추가했다.

| 구분 | 아이템 | 차지하는 칸 |
|---|---|---|
| 장식 | 장미 아치 / 꽃울타리 | 2×1 / 1×2, 방향 변경 가능 |

새 개별 원화9종은 built-in image_gen으로 제작했고 원본·정확한 프롬프트·생성/저장 경로는 `packages/garden-world/art/expansion-prompts.json`에 기록했다. 총 원화17종, 배치 아이템16종이다. 소스 원본은 보존하고 파생 PNG만 기술적 알파 정리/크기 정규화를 한다.

## 사용 흐름

하단 상점 → 전체/장식/시설/동물 분류 → 이미지 상품의 체험 구매 → 해당 사본을 보관함에 지급 → 즉시 지도 배치 미리보기 → 드래그/방향 선택 → 배치 확정. 배치를 취소하면 구매한 사본은 보관함에 남는다. 이미 놓은 물건과 동물은 선택 후 회수해서 다시 놓을 수 있다.

동물도 사본별 고유 ID와1칸 점유를 사용한다. 물건/동물과 같은 칸에 겹쳐 놓을 수 없고, 산책로 위에는 놓을 수 있다. 현재 동물은 타일에 배치하는 정적 원화이며 자유 산책·먹이·교감·상태 변화는 추가하지 않았다.

체험 구매는 무료 샘플 지급이다. 실제 코인/별/결제/영수증 검증/API를 사용하지 않는다. 상점과 배치 기능은 독립 미리보기에만 연결했다. 실제 메인 게임의 판매 상품·가격·서버 소유권 연결은 후속 범위다. 이야기 주요 건물은 상품 목록에서 제외한다.

## 보존과 요청 처리

- 기존 체험 저장 키와 데이터 구조를 유지하여 이전 배치/보유권을 초기화하지 않는다. 새 아이템은 구매할 때만 추가한다.
- 같은 구매 키 재시도는 같은 사본을 반환한다. 같은 키로 다른 상품을 요청하면 거부한다. 다른 구매 키는 별도 사본을 지급한다.
- 정원에 놓을 공간이 없으면 받은 물건은 보관함에 유지한다. 저장 검증 한도1000사본을 넘기는 새 구매는 거부하며, 한도에서 이전 구매 재시도는 허용한다.
- 분류를 바꾸면 해당 목록이 처음부터 표시된다. 좁은 화면에서도 상점 마지막 행까지 스크롤할 수 있고 하단4개 메뉴가 화면 안에 들어간다.

## 이번 검증

Vitest3파일28검사, TypeScript, 독립 Vite 빌드 통과. HTTP38파일14,615,755바이트가 빌드 원본과 일치하고 API 처리기가 없음을 확인했다.

공식 CUA Chrome에서402×874/360×780뷰포트로 실제 페이지를 열어 다음을 직접 확인했다. IAB는 제공되지 않아 Chrome을 사용했으며 별도 브라우저 자동화는 사용하지 않았다.

- 상점14상품, 동물3상품, 이미지 정상 로드와 분류 전환.
- 토끼 체험 구매→실제 마우스 입력 드래그→18,21칸 배치→새로고침 후 같은 배치 복원.
- 지도 위 토끼를 클릭→보관→보관함1개 표시.
- 고양이 체험 구매→배치 취소→보관함1개 유지.
- 정자 체험 구매→3×3배치 미리보기→16,19칸 확정.
- 360px상점 마지막 행 도달(scrollTop1206, clientHeight434, scrollHeight1640), 수평 넘침0, 깨진 이미지0. 긴 목록에서 동물 분류로 전환한 뒤 scrollTop0 확인.
- 방문 모드의 상점/보관함 비활성. 관찰한 콘솔 warning/error0.

증거는 `output/verification/garden-world/animals-browser/`에 있다. 물리 기기의 터치·실결제·서버 거래·동물 이동 AI 검증으로 확대해서 주장하지 않는다.

검수 전 체험 저장 값은 없었으며, 종료 때 이번 UI 검수로 만든 구매/배치 키만 원복했다. 동시 변경이 있으면 덮어쓰지 않는 비교 후 복원 방식이며 cleanup 결과가 true였다. 다른 게임 키/실제 계정/DB에는 접근하지 않았다. 해당 검수 탭의 임시 화면 크기를 원복하고 사용자용 동물 상점을 열어두었다.
