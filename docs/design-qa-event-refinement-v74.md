# 이벤트 시안 대조·보정 v74

## 범위와 기준

현재 실행 화면 5종을 먼저 캡처한 뒤 사용자 선택 시안과 비교했다. 동물 구출 원정·핀볼·온실은 `output/playwright/event-design-v62/selected-reference-normalized.jpg`의 세 패널을 기준으로 삼았다. 패스·프리미엄·우편함은 보존된 `events-v3-rewards-pass.png`를 기준으로 삼았다. 이전 v73의 메뉴별 새 헤더와 탭은 유지했다. 현재 시안의 예시 보상과 실제 게임 규칙이 다르면 서버가 정하는 수량·규칙을 유지했다.

시안대로 핀볼의 물리적인 빨간 버튼, 온실의 청록 버튼, 원정의 초록 버튼은 각각의 장면에 남겼다. 출석·우편의 행 안 받기 버튼은 해당 행 안에서 유지했다. 시즌의 제거된 플레이 버튼은 다시 추가하지 않았다. 꽃빛 배경의 그려진 버튼은 아래쪽만 새 원화로 복구해 실제 버튼과 중복되지 않게 했다.

새 원화16개와 생성 참조·프롬프트·준비 과정은 `packages/assets/event-design-v62/event-refinement-v74-prompts.json`에 보존했다. 기존 원본은 삭제하지 않았다.

## 실제 데이터와 의도적인 차이

- 핀볼은 기존 게임이 5포켓이고 목표 포켓 보너스50/일반5다. 시안의 4포켓/50·100·복원·200 예시로 물리 규칙을 바꾸지 않았다.
- 온실은 기존10단계를 유지하며 선반은1–5 또는6–10구간을 표시한다. 실제 맵의 목표 화분3곳과 초기 미연결 상태가 시안의 예시3/5 연결 화면과 다르다.
- 원정 동물은 회차 데이터를 따른다. 배경에 예시 판다나 보상을 고정하지 않았다.
- 현재 API의 패스는30단계, 단계×10점, 무료25코인/프리미엄75코인, 5단계마다 망치다. 프리미엄 합계는2250코인·망치6·프로필문장1·길드선물권1이다. 시안의100/500 등 예시 수량을 지급 규칙으로 옮기지 않았다.
- 우편 보상은 실제 응답을 표시한다. 요약은 오늘의 획득분으로 오인하지 않도록 ‘받은 보상’으로 표시한다.

## 실제 브라우저 검수

실제 React 컴포넌트와 production 빌드 CSS를 사용한 로컬 fixture를 Chrome에서 조작했다. 계정·API·시간은 합성이며 운영 지급이나 결제는 수행하지 않았다. 패스 fixture도 실제 CommunityMenus와 CommerceDialog를 사용한다.

2. 패스4단계 무료 수령→5단계 선택, 모두 받기→13단계 선택을 확인했다. 단계 페이지 전후 이동도 확인했다. 실패/동일 응답에서는 선택을 바꾸지 않는 단위 테스트를 포함했다. 프리미엄 복귀 후 dialog1개/inert0. 보유 계정의 길드선물권 버튼→별도 모달 열림 확인, 선물 발송은 하지 않았다.
3. 핀볼 도전 시작→7개 발사 위치, 중앙 발사→공 이동/발사 잠금 확인. 최종 별/점수 분리 측정. 온실 시작→수로 회전 시 남은 회전12→11, 물 준 화분0/3→2/3 확인. 원정 홈 버튼→홈 복귀 확인.
4. 우편 단건/모두 받기 후 합계500코인·복원5·망치1·로켓3 확인. 390px 하단 버튼은 꽃빛/도구/보물/우편 모두 x58.5, 너비273, 높이54.59, 본문 하단 여백7.8px로 일치했다.
