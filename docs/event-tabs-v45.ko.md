# 이벤트 아이콘 탭 v45

이벤트 페이지의 세로 콘텐츠 목록을 가로 아이콘 탐색과 선택한 이벤트 본문으로 변경했다.

## 동작

- 출석 선물이 첫 번째 탭이다. 이벤트 메뉴에 들어오거나 푸터의 이벤트를 다시 누르면 출석 선물로 돌아간다.
- 꽃빛축제, 동물 구출 원정, 보물 카드, 도구 축제, 시즌 이벤트, 시작 아이템 무제한을 같은 줄에서 선택한다. 운영 보상 이벤트가 있으면 해당 탭도 표시한다.
- 한 화면에 약 4.5개가 보이고, 나머지는 가로 스크롤한다. 선택한 아이콘은 완전히 보이는 위치로 이동한다.
- 상단 아이콘 줄을 유지하고 선택한 이벤트 본문 하나만 아래에서 스크롤한다. 기존 이미지 자산을 재사용했다.
- 꽃빛축제와 구출 원정은 기존 해금 레벨을 유지한다. 구출 원정은 레벨 20부터 표시한다.
- 구출 원정의 실제 퍼즐은 전체 게임 영역에서 실행하고, 나가면 같은 탭의 이어하기 메뉴로 돌아온다.
- 보상 수령 또는 플레이/재개가 가능하면 빨간점을 표시한다. 출석 수령, 완료한 원정, 보상 없는 만료 이벤트는 해당 점을 제거한다. 시즌 보상은 서버 수령 조건과 동일하게 시즌 진행 중에만 표시한다.
- 키보드 방향키와 Home/End 선택을 지원한다. 바깥 레이아웃의 overflow:clip과 가로 전용 스크롤로 포커스 이동 시 헤더가 밀리지 않도록 했다.

## 검증

- 클라이언트 전체 빌드 및 TypeScript 검사 통과.
- 이벤트 탭 상태, 다국어, 콘텐츠 이벤트, 도구 축제 관련 4개 테스트 파일 / 31개 테스트 통과.
- 실제 컴포넌트를 사용하는 독립 브라우저 fixture에서 320, 390, 540px 폭을 확인했다. 보이는 아이콘 수는 각각 약 4.501, 4.501, 4.501개였으며 가로 넘침이나 누락 이미지는 없었다.
- 출석 수령 후 점 제거, 이벤트 재진입 시 기본 탭 초기화, 선택한 본문만 마운트, 꽃빛축제 자동 입장/이야기, 보물 카드 시작, 도구 축제 시작, 원정 전체 화면 진입/복귀/재개를 확인했다.
- 본문을 140px 스크롤하는 동안 아이콘 줄의 화면 위치는 121px로 유지됐다. 영문 라벨 영역 높이는 모두 40px였다.
- 합성 상태와 차단된 mock API로 검사했다. 운영 사용자 데이터 변경 및 실물 Android/iOS 검증은 하지 않았다.
- 이번 변경은 서버 배포나 네이티브 동기화를 포함하지 않는다. 앱 반영은 `npm run native:release`로 진행한다.

근거: `output/verification/event-tabs-v45/`의 화면, browser-proof.json, tests.log, client-build.log.

## 시즌 빨간점 수정

- 기존 아이콘의 시즌 빨간점은 출석까지 포함하는 전체 이벤트 알림 합계를 사용했다. 이전 fixture용 컴포넌트도 시즌 전용 수령 가능 개수만 받도록 수정했다.
- 현재 탭의 시즌 알림은 목표 미달 상태까지 표시하던 조건을 수정했다. 진행 중인 시즌에서 목표를 달성했고 아직 수령하지 않은 개인/가입한 길드 보상이 있을 때만 표시한다.
- 개인·길드 보상 모두 수령 완료, 목표 미달, 길드 미가입, 시즌 종료/없음에 대한 회귀 테스트를 포함해 관련 16개 테스트 및 TypeScript 검사를 통과했다.
- 합성 브라우저 상태에서 출석 알림이 남아 있어도 시즌 알림이 꺼짐을 확인했다. 마지막 시즌 보상 수령 직전에는 표시되고 수령 직후에는 사라졌다. 근거: `season-claimed-no-dot.png`, `season-dot-proof.json`.
- 서버/네이티브 배포는 하지 않았다.
