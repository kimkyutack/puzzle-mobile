# 로컬 퍼즐·음소거·테두리 폭죽

- 타일 교환, 매치, 특수 타일, 소모 아이템은 같은 결정론적 엔진으로 기기에서 즉시 처리한다. 입력 잠금은 연출이 끝나면 풀며 HTTP 완료와 연결하지 않는다.
- 행동은 계정별 로컬 기록에 먼저 보관하고 약 2.2초 단위로 묶어 전송한다. 불확실한 응답은 동일 키·시퀀스·행동 묶음으로 재시도한다. 전송 중 추가한 행동은 확인된 접두부 뒤에 남는다.
- 화면의 아이템 보유량은 서버 보유량에서 미확인 사용 횟수를 뺀 값이다. 서버는 일괄 재생과 수량 차감을 하나의 D1 트랜잭션으로 수행한다. 보유하지 않은 아이템이 포함되면 그 묶음 전체를 거절한다.
- 서버 확인 응답이 로컬 보드와 같으면 기존 화면 상태 객체를 유지하여 연출·드래그를 초기화하지 않는다. 실제 충돌은 미저장 기록을 보관하고 서버 진행을 불러온다.
- 진행 중 연결이 끊겨도 로컬 조작과 보유 아이템은 사용할 수 있다. 새 판 시작, 유료 +5 이동, 최종 보상은 서버 확인이 필요하다. 오프라인 상태에서 앱을 완전히 새로 실행하는 기능은 별도 범위다.
- 효과음 끄기는 재생 중인 모든 효과음도 즉시 음소거·정지한다. 음악 끄기는 광고·백그라운드 복귀 이후에도 유지한다. 설정은 기기에 먼저 저장하고 서버에 반영될 때까지 오래된 응답보다 우선한다.
- 새 `sweep-border` 아이템(테두리 폭죽)은 외부 빈 공간과 맞닿은 플레이 영역 전체를 한 번씩 타격한다. 닫힌 내부 구멍은 외곽이 아니다. 다중 칸 장애물은 한 번만 손상되고 색상 장애물에도 한 층 피해를 준다. 이동 횟수는 쓰지 않는다. 상점 가격은 350 코인이며 기존 계정의 누락된 재고는 0으로 호환한다.
- 신규 아이콘: `packages/assets/source/sweep_border_v13.png`. 생성 기록: `packages/assets/border-booster-v13.json` (built-in image_gen).
- 타일 이미지 투명 여백을 7%에서 약 1.2%로 줄이고, 칸 대비 표시 크기를 96%에서 99%로 늘렸다. 프레임 안쪽 마스크는 유지한다.

검증: 전체 Vitest, `tools/api-local-play-http.ts`, `tools/api-heart-failure-http.ts`, 배포 후 `tools/api-cloudflare-check.ts`. 화면·음향 검증 결과는 `output/verification/`에 저장한다.

디자인 참고: 사용자 제공 Royal Match 플레이 스크린샷 및 [Dream Games 공식 자료](https://www.dreamgames.com/games/royal-match). 서버 검증 방식은 기존 D1 원자적 변경 규칙을 유지한다.
