# 큰 정원 지도와 꾸미기 아이템

2026-11-03 사용자 결정: 카메라를 이동·확대하는 큰 격자 정원에서 건물과 장식을 직접 배치한다. 이후 상점에서 꾸미기 아이템을 판매하고 구매한 아이템을 정원에 건설할 수 있게 한다. 순위표의 정원사 프로필에서 실제 저장된 정원을 방문한다.

## 플레이 흐름

퍼즐 클리어 → 기존 별 획득 → 이야기의 새 구역/주요 건물 해금 → 정원에서 배치와 꾸미기 → 완성된 공간에서 이야기 진행.

추후 판매 흐름은 상점의 이미지 상품 → 구매 승인 → 꾸미기 보관함 → 정원에 놓기 → 위치/방향 미리보기 → 배치 확정이다. 이미 보유한 물건은 회수해 다시 배치한다. 이동·회수·재배치에 구매 비용을 다시 부과하지 않는다. 같은 물건 여러 개를 사면 각 사본을 별도 보유 인스턴스로 관리한다.

## 지도와 화면

- 첫 지도 초안32×32칸, 처음 열린 하늘 정원12×12칸. 온실 작업실·분수 테라스·연못 정원·숲속 산책길을 이어 붙이는 구역 구조다. 정확한 크기/풋프린트는 새 등각 시점 원화와 함께 확정한다.
- 배경 드래그는 카메라 이동, 두 손가락은 확대/축소. 편집 중에만 격자를 표시한다. 건물 선택→이동/방향 선택→확정/취소이며 미리보기 단계에는 저장 요청을 하지 않는다.
- 건물은 점 좌표가 아니라 실제 차지하는 칸을 가진다. 회전하면2×1벤치가1×2로 바뀐다. 이미 놓인 물건·잠긴 땅·지도 밖에는 확정할 수 없다.
- 땅 재질/산책로와 건물은 별도 층이다. 같은 층의 사본은 겹칠 수 없고, 포장 위에는 물건을 놓을 수 있다. 주민 길찾기는 최종 건물 점유를 고려한다.
- 주요 온실/분수는 이야기 구역 안에 배치하고, 길·꽃·나무·벤치·조명은 열린 공간에서 조합한다. 완공 때 카메라가 해당 위치로 이동해 변화와 주변 풍경을 보여준다.
- 방문 화면은 같은 지도 렌더러에 읽기 전용 공개 배치를 사용한다. 귀환하면 순위 목록 위치와 선택 탭을 유지한다.

## 보유와 판매 계약

퍼즐의 망치/부스터 인벤토리와 건설·장식 보관함을 구분한다. `Player.inventory`, 기존 별/코인 정책과 퍼즐 규칙은 변경하지 않는다.

| 구분 | 역할 |
|---|---|
| 장식 정의 | 아이템 ID, 풋프린트, 허용 방향, 디자인, 지도 층, 허용 구역 |
| 보유 사본 | 고유 인스턴스 ID, 아이템 ID, 디자인, 승인된 획득 경로 |
| 배치 | 보유 사본 ID, 격자 좌표, 방향 |
| 지급 기록 | 복원/이벤트/검증된 구매에서 받은 고유 지급 ID |
| 상품 | 후속 상점 카탈로그에서 보유 사본 지급에 연결. 현재 판매 가격/상품은 게시하지 않음 |

`futureShop=true`는 추후 상품화 가능한 장식이라는 뜻이며 판매 중이라는 뜻이 아니다. 별도 상품 게시/실제 가격/구매 승인 경로가 있어야 지급한다. 이야기 주요 건물은 상점 장식과 분리한다. 선물/이벤트 꾸미기 역시 승인된 지급 이후 같은 보관함으로 들어간다.

추후 코인 상품이라면 코인 차감과 소유권 지급을 서버의 한 거래로 처리한다. 실결제 상품은 기존 영수증 검증 성공 후 고유 거래 키로 한 번만 지급한다. 이동/회수 요청은 아이템을 새로 지급하거나 재화를 차감하지 않는다. 구매 취소·환불의 장식 회수 정책은 실제 상품 도입 전에 확정한다.

## 이번에 추가한 독립 기반 모듈

`packages/garden-world/src/`에 타입/초안 카탈로그, 등각 카메라 좌표 변환·줌·이동 제한, 소유/배치/회수 규칙, 지급·요청 재시도 키, 구역/점유/회전 검증, 방문용 공개 배치 투영을 추가했다. 서버와 클라이언트가 같은 순수 규칙을 재사용할 수 있다. 이 모듈은 현재 앱의 화면·API 라우트·DB·결제·실제 계정 상태에 연결하지 않았다. 다른 진행 중인 UI 수정과 충돌하지 않도록 기존 파일은 수정하지 않았다.

이 기반 모듈만으로 서버 권위나 실결제가 구현된 것은 아니다. 통합 시 인증된 actor ID를 서버 세션에서 가져오고, 소유자 확인과 원자적 revision 비교를 DB 거래 안에서 실행해야 한다. 지급/배치 재시도 키는 고유 DB 테이블에 보관한다. 클라이언트가 보낸 소유권/구매완료/구역해금 정보는 신뢰하지 않는다.

공개 방문 응답에는 배치된 아이템 ID·디자인·좌표·방향과 열린 구역만 담는다. 남은 보관함, 지급 영수증, 작업 요청 기록, 재화, 설정, 인증 정보는 보내지 않는다. 프로필의 닉네임·기록·길드는 별도의 명시적인 공개 필드로 합친다.

## 통합 순서와 미완료 범위

1. 등각 시점의 땅/길/건물/그림자 원화와 방향별 이미지를 제작한다. 기존 정면 소품을 단순히 회전·늘려서 지도 아트로 사용하지 않는다.
2. 전용 지도 렌더러와 터치 카메라, 건설 미리보기·보관함을 연결한다. 홈과 방문은 같은 배치 데이터를 그린다.
3. 인증된 조회/배치/회수 API와 DB 저장·동시 수정 처리를 붙인다. 방문 조회는 공개 투영만 반환한다.
4. 기존 복원 ID와 무료 선택을 유지하는 보유권 이관을 설계·검증한다. 이미 소비한 별을 재청구하거나 기존 복원 기록을 초기화하지 않는다. 아직 이관을 실행하지 않았다.
5. 순위→프로필→실제 정원 방문을 연결한다.
6. 후속 상점에 이미지 중심 꾸미기 상품과 승인된 구매→보관함 지급을 연결한다. 가격·추가 재화·건설 대기시간은 이번 변경에서 도입하지 않았다.

초기 기반 단계의 결과는 후속 통합용 규칙 모듈과 기획이다. 이어서 독립 지도 체험 화면을 추가했으며 현재 범위와 검증 한계는 `garden-world-preview.ko.md`에 기록했다. 기존 홈 전환, 네이티브 설치, 공개 조회 API, DB 저장, 실제 상품 판매는 아직 통합하지 않았다.
