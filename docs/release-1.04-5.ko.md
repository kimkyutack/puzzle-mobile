# iOS 1.04 (5) 운영 반영

2026-11-05 15:33 KST에 현재 서버 소스를 `puzzle-mobile` Worker에 배포했다. 새 버전은 `e2af30e2-9be3-42e2-bce6-f8f707445d5c`이며 트래픽 100% 전환을 확인했다. API 주소는 `https://puzzle-mobile.ddr1323.workers.dev/api`다.

## 반영 범위

- 엔진 1.3.0과 승인된 10,000개 퍼즐, 새 기믹을 제공한다. 1.0.0·1.1.0·1.2.0 요청에는 각 버전의 기존 콘텐츠를 제공하며 저장된 판도 계속 재생한다.
- 기존 18개 복원 뒤 45개 작업과 이야기가 이어진다. 총 63개 복원·64개 장면이며 복원은 별 차감과 시설 저장을 한 트랜잭션으로 처리하고 Player와 world를 함께 반환한다.
- 일일 구조 보상과 출석 처리, 기존의 20칸당 1,000코인 정원 확장·묶음 구매·드래그 설치·4방향 회전을 포함한다.
- 기존 D1·R2·Durable Object 바인딩, Smart Placement, 운영 변수와 크론을 유지했다. 미적용 DB 마이그레이션은 없으며 사용자 데이터 초기화는 하지 않았다.
- iOS Debug·Release의 표시 버전은 `1.04`, 빌드는 `5`다. 설정 화면은 설치된 앱의 실제 버전·빌드를 표시한다. 아카이브·스토어 업로드는 수행하지 않았다.

## 검증

- Vitest 53개 파일·343개 테스트와 TypeScript 검사, 웹 빌드, 운영 설정 Worker 패키징을 확인했다. 대량 맵 인증은 수백 개 경로를 재생하므로 개별 테스트 제한을 60초로 두었다.
- 실제 Worker와 임시 D1에서 새 엔진의 대표 18개 맵을 시작·재생·보상 정산했다. 1~10,000의 경계와 새 기믹 구간, 기존 엔진 3종의 콘텐츠, 미공개 구간의 무차감을 포함해 22개 항목을 확인했다.
- 실제 Worker와 임시 D1에서 연속 복원 6개, 정원 확장 6개, 일일 구조 7개 검증 그룹을 통과했다. 기존 엔진 1.2.0의 200개 맵·1,429개 행동은 배포 전 소스와 상태 해시 및 이벤트가 일치했다.
- 운영 API에서는 배포 전에 생성한 1.2.0 판을 배포 뒤 그대로 이어서 클리어했다. 새 엔진으로 20개 판을 클리어하며 로컬 상태 일치·중복 정산 방지·10회 클리어 보상·하트 유지를 확인했다.
- 운영 API의 63개 복원 목록, 복원 결과와 재조회 일치, 이야기 감상, 1,000코인 확장, 새 땅의 회전 장식 저장, 일일 구조 중복 보상 방지와 출석 수령을 확인했다. 생성한 검증 게스트 2개는 모두 삭제했다.

검증 도구는 `tools/api-campaign-http.ts`, `tools/api-story-v30-http.ts`, `tools/api-garden-expansion-v28-http.ts`, `tools/api-daily-rescue-http.ts`, `tools/api-release-smoke.ts`에 있다. 상세 결과는 로컬의 `output/verification/release-104-5/`에 보관하며 인증 설정·설치용 산출물과 함께 Git에서는 제외한다. 실제 기기 설치 및 아카이브 검증은 별도다.
