## 외부 설정과 미검증 범위

- Cloudflare D1 ID, R2 버킷/custom domain, Worker URL·환경·secrets가 필요합니다. 현재 리소스 ID는 로컬용입니다.
- Google/Apple OAuth 앱·클라이언트 ID, Apple 인증 철회 키, 스토어 상품·결제 API 키/계정, AdMob 앱·광고 단위·SSV·동의 설정에 실제 운영 값이 필요합니다. 정확한 변수명은 `.env.example`, `native-services.md`에 있습니다.
- 실계정 로그인/다른 물리 기기 계정 복구, sandbox 구매/환불, 실제 광고 시청/SSV 지급, 운영 웹훅 전달은 미검증입니다.
- 물리 저사양 기기의 FPS·GPU 메모리·발열·배터리·실제 네트워크 지연은 측정하지 않았습니다. 에뮬레이터/시뮬레이터 결과를 물리 기기 성능으로 해석하지 않습니다.
- 201 이후는 검증된 후기 60개 정의의 순환 공급입니다. 후보 생성·검증 도구는 제공하지만 매판 미검증 보드를 무한 생성하지 않습니다.
- 영어는 부분 번역입니다. 미술은 실제 PNG와 keyframe/transform 애니메이션이며 모든 포즈를 개별적으로 다시 그린 것은 아닙니다. 이미지 전체를 시작 시 검증·캐시하고 GPU 배경은 화면 소유자가 없어질 때 해제합니다. 대규모 지역 팩 스트리밍은 구현하지 않았습니다.
