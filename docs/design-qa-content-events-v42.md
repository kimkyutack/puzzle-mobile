# 꽃빛축제·동물 원정 검증

- 타입 검사, 클라이언트 프로덕션 빌드, 관리자 빌드, 운영 Worker dry-run 통과. 실제 운영 배포 및 네이티브 동기화/아카이브는 실행하지 않음.
- 이벤트 거래/해금/재생/호환성, 운영 콘솔, 기존 실행 게이트웨이/정원 관련 최종 집중 검사 통과. 신규 콘텐츠 테스트는 10개.
- 전체 실행에서는 541개 중 540개가 통과했고 기존 `campaign-bulk`의 대량 맵 검증 1개가 60초 제한에 걸림. 해당 파일을 수정 없이 단독 재실행하여 5개 모두 통과(36.75초). 이후 추가한 호환성 테스트를 포함한 집중 검사 4파일 41개 통과. 로그와 실제 실행 범위를 구분하여 기록함.
- 원정 전용 길 5종과 각 코스의 배치 3종, 총 15개가 구매 도구 없이 승리 재생됨. 강제 섞기 0회. 자동 승리 경로 검증이며 사람의 승률을 뜻하지 않음.
- 격리된 로컬 Worker 실제 HTTP: 레벨 19 원정 거부 → 20 허용, 원정 5코스, 일반 레벨 20회 클리어, 축제 5단계, 중복 보상 거부, 분수·토끼 보관함 지급, 분수 180도 설치, 구형 앱의 분수 대체 응답 통과.
- 실제 UI 컴포넌트와 가상 응답을 사용하는 로컬 화면에서 320×658, 390×844, 540×900 확인. 가로 넘침과 누락 이미지 없음. 작은 화면의 세로 콘텐츠는 모달 내부에서 스크롤.
- 브라우저에서 레벨 19/20 표시 전환, 분수 2→3단계 복원과 대화, 저장된 원정 복구, 타일 드래그, 클리어 연쇄 후 보상 버튼, 다음 코스 입구, 보관함 이동을 확인.
- 원정 진행 수치는 보드에서 실제 표시하는 연쇄 프레임에 맞춰 갱신. 버튼 이미지와 활성/완료 표시, 밝은 카드의 텍스트 대비를 확인.
- 실기기 iOS/Android FPS와 네이티브 안전영역은 이번 검사에서 직접 측정하지 않음.
