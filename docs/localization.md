# 구름정원: 루미의 초대장 — 한국어·영어

한국어 제목은 **구름정원: 루미의 초대장**, 영어 제목은 **Cloud Garden: Lumi's Invitation**입니다. 화면 로고는 `packages/assets/branding/title-ko.png`와 `title-en.png`로 각각 제작했습니다. 제작 원본과 정확한 프롬프트는 같은 폴더의 `prompts.json`에 보존하며, 첫 언어 선택·로딩 화면에서는 알파를 유지한 1200px WebP를 사용합니다. 일반 타일 atlas와 분리해 앱 시작 전에도 번들에서 불러옵니다. `BrandLogo`가 현재 언어의 이미지와 접근성 이름을 선택하고 가로세로 비율을 유지합니다.

## 첫 실행과 설정

- `LanguageGate`는 저장한 언어가 없으면 한국어 / English 선택 화면을 먼저 표시합니다. 기기 언어는 안내문·로고의 초기 표시만 결정하며 사용자의 선택을 대신하지 않습니다. 선택 전에는 App을 마운트하지 않아 게스트 생성·게임 시작·하트 사용이 발생하지 않습니다.
- 선택은 `cloud-garden-language-v1`에 즉시 저장하고 화면에 적용합니다. 계정 로딩이 끝나면 `/me` PATCH로 `settings.language`만 동기화합니다. 기본 서버 언어가 사용자가 방금 고른 언어를 덮어쓰지 않습니다.
- 설정 > 언어에서도 한국어 / English를 변경합니다. 즉시 반영하고 서버에 저장하며, 실패한 저장은 로컬에서 대기 상태를 유지해 다음 로딩 때 다시 시도합니다. 재접속에도 선택이 유지됩니다.
- 이전 저장 응답이 늦게 도착해도 더 최근 선택을 지우지 않습니다. 계정 전환 시에는 대기 중인 변경이 없으면 해당 계정에 저장된 언어를 사용합니다.
- 언어 변경은 퍼즐·재화·아이템을 변경하는 요청을 보내지 않습니다. 앱 ID, 기존 토큰 키, 진행 저장 구조는 이름 변경과 분리해 유지합니다.

## 번역 구조와 범위

`apps/client/src/i18n.ts`의 공용 키는 `t('hud.level', {level: 12})`로 사용합니다. 원문 기반 문구는 `locales/catalog.en.json`에 있으며 `tr('함께 자라는 정원')`, `tr('{0}님의 {1} {2}개', {0: nickname, 1: itemName, 2: count})`처럼 호출합니다. 치환값 자체는 다시 번역하지 않아 사용자 이름이 시스템 문구와 같아도 보존합니다.

번역 대상은 홈·상점·패스·순위·길드·선물함·설정·프로필·게임 HUD·목표·아이템·보상·구매 확인·계정 안내·오류·튜토리얼, 현재 세 지역의 이름과 18개 복원 작업, 19개 이야기의 64개 대사와 인물·장 제목입니다. 서버 사용자 오류 93개는 코드별 영어 사전을 제공합니다. 알려지지 않은 한국어 서버 오류는 영어에서 읽을 수 있는 재시도 안내로 표시합니다.

닉네임·길드 이름·소개·채팅·사용자 공지는 원문을 보존합니다. 운영체제와 외부 인증·결제 SDK의 자체 화면은 해당 공급자의 언어 정책을 따릅니다. 공식 공급자 로고 및 기존 원화에 포함된 문구를 임의로 재제작하지 않습니다. 별도 `garden-world` 실험 화면은 현재 앱 경로가 아니며 이 검사의 대상에서 제외합니다.

## 문구 추가와 검증

새 화면에는 한국어 JSX 문자열 대신 `t` 또는 `tr`를 사용하고 대응하는 영어 번역을 추가합니다. 공통 키는 두 언어의 키가 타입 검사로 일치해야 합니다. 원문 기반 문구의 `{0}` 등 자리표시자는 번역에서도 같은 개수를 유지합니다. 날짜·숫자 표시에는 `formatLocale()`을 사용합니다. 새 언어 추가 시에는 Locale 타입, 선택 버튼, 번역 사전, API 언어 계약, 네이티브 리소스도 함께 확장합니다.

```bash
node tools/check-localization.mjs
npx vitest run tests/client-i18n.test.ts tests/client-language-preference.test.ts
npm run typecheck
```

검사 도구는 앱 소스의 리터럴 `tr` 호출 누락, 번역되지 않은 JSX 한글, 영어 사전의 한글 잔존 및 자리표시자 불일치를 확인합니다. 동적 콘텐츠 테스트는 모든 현재 이야기·인물·지역·복원 이름을 확인합니다. 테스트는 선택 전 게임 미실행, 선택 우선순위, 저장 실패·경합·재접속 및 사용자 문구 보존도 다룹니다.

이번 브라우저 검수는 별도 localhost 출처와 합성 플레이어·가짜 API 응답으로 수행했습니다. 실제 개발 계정·진행·재화는 건드리지 않았으며 실제 서버 왕복 검증과 구분합니다. 근거는 `output/verification/localization/`에 저장합니다.

## 네이티브 이름

Android 기본/ko/en 문자열과 iOS ko/en InfoPlist.strings에 짧은 홈 화면 이름(구름정원 / Cloud Garden)을 등록했습니다. Android Activity·웹 문서 제목·설정 버전 안내는 전체 제목을 사용합니다. iOS Xcode 리소스 그룹에 번역 파일을 등록했습니다. 이번 작업에서 네이티브 앱을 재빌드·재설치하지 않았으므로 설치된 앱에는 다음 네이티브 빌드부터 반영됩니다.
