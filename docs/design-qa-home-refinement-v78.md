## 발견과 수정

1. **P1: 비슷하게 생성한 UI 원화의 차이.** 버튼 녹색·코랄색, 봉투/패스/트로피/클립보드/무한대/판다/하단 아이콘 등이 원본과 달랐다. 실제 원본에서 각 요소를 분리해 배경을 매팅했다. 버튼은 원본 모서리·광택·그림자 픽셀을 보존하고 문자/아이콘이 덮인 부분만 주변 원본 색으로 복원했다. 큰 세로 스트립을 늘렸을 때 생긴 접합선도 발견해 문자 마스크를 확장한 국소 보간으로 수정했다.
2. **P1: 정원 타일 재생성으로 인한 질감 차이.** 잔디와 판석을 새로 비슷하게 만드는 방법을 중단하고 원본의 실제 한 셀을 affine 추출했다. 잔디 원본 패치 RGB 차이0, 기존 마스크 알파 차이0. 낡은 크림 판석의 모서리·잔디 이음도 보존했다. 판석의 초록 배경만 별도 오버레이에서 투명화하고 이웃 길에 따라 직선/회전/교차를 연결했다.
3. **P2: CSS 위치·비율·표면 차이.** 원본을 기준으로 메뉴 사이 간격/구분선, 버튼 폭·간격·반경·그림자, 연승 캡슐과 강화 무지개등의 연결 영역, 숫자 캡슐, 둥근 도구 축제 표면, 선택 홈 탭, 헤더 아이콘/카운터, 선물함 위치를 보정했다. 홈 유틸 아이콘 밑 타이머는 시안에 없어 시각 노출을 제거했으며 해당 상세 페이지와 접근성 타이머는 유지한다. 가득 찬 하트는 시안처럼 숫자만 표시하고 충전 중 타이머는 유지한다.
4. **P2: 작은 화면 넘침.** 고정 구분선이 추가되며320px의 마지막 메뉴2개가 최소44px를 넘었다. 좁은 화면 트랙을4개 가변+8px 간격+44px2개로 수정했다. 한·영·일 재촬영에서 가로 넘침과 버튼 문구 잘림이 없다.
5. **P1: 동일한 패키지 이미지.** 한정 패키지 원화는 그대로 두고 연쇄 전용 청록/파랑 계단형 선물 이미지로 분리했다. 실제 각 패키지 모달로 연결된다.
6. **P1: 시안 조경을 구입할 수 없음.** 벚꽃나무·꽃 아치 벤치·꽃3종·화분 세트·작은 나무를 실제 상점/소유/배치 모델에 추가했다. 앞/뒤 그림과 가격, 수량, 서버 결제 및 구버전 호환도 연결했다.
