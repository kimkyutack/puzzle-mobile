# 정원 건축 스플래시 포스터

루미가 판다·여우·토끼와 함께 푸른 구름 정원에 정자를 짓는 오리지널 스플래시입니다. 내장 `image_gen` 도구로 세로·가로 포스터를 제작하고 Sharp로 웹·네이티브 시작 이미지를 출력했습니다. 전체 프롬프트는 `prompts.json`에 보관했습니다.

- 원본: `source/garden-build.png` (941×1672), `source/garden-build-wide.png` (1536×1024).
- 웹/앱 로딩: `apps/client/public/splash/garden-build-v52.webp`, `garden-build-wide-v52.webp`.
- iOS: `Splash.imageset`의 기존 1x/2x/3x 참조를 유지하면서 360×640, 720×1280, 1080×1920 포스터로 교체. 기존 파일명에 남은 `2732x2732`는 이전 파일 이름이며 실제 크기는 `native-assets.json`에 기록했습니다.
- Android: 기존 기본/세로/가로 밀도별 `splash.png` 리소스를 같은 크기의 새 포스터로 교체. 런치 테마의 배경색만 포스터의 하늘색과 맞췄으며, 게임 실행 중 시스템 바·배경 설정은 변경하지 않았습니다.
- 재출력: `node --import tsx tools/build-splash-v52.ts`.

초기 HTML에 포스터와 반응형 이미지 선로딩을 넣어 전체 게임 번들·아틀라스 준비 전부터 표시합니다. `StartupPoster`는 실제 로딩 화면과 최초 언어 선택에서 같은 원화를 사용합니다. 정사각형보다 넓은 화면에는 가로 원화를 선택합니다. 짧은 가로 화면은 로고와 진행 표시를 왼쪽으로 옮겨 동물 얼굴을 가리지 않게 했습니다. 기존 오류 안내·일반 재시도·계정 재연결·언어 선택 동작을 유지합니다.

Android 12 이상의 최초 OS 스플래시는 플랫폼이 앱 아이콘과 단색 배경으로 표시합니다. 이 시스템 화면이 끝난 뒤 앱의 전체 포스터가 이어집니다. 전체 포스터를 시스템 아이콘 영역에 강제로 넣지 않았습니다. 근거: [Android 공식 Splash screens 문서](https://developer.android.com/develop/ui/views/launch/splash-screen).

검증 기록은 `output/verification/splash-v52`에 있습니다. 타입 검사, 관련 테스트 8개, 격리된 프런트엔드 빌드, Android XML 검증, iOS LaunchScreen 스토리보드 컴파일을 통과했습니다. 브라우저에서 390×844, 320×658(영문), 690×844(폴더블), 844×390(가로), 초기 HTML 포스터, 계정 재연결 콜백 및 언어 선택 완료를 확인했습니다. 이미지 누락·가로 넘침·콘솔 오류는 없었습니다.

기존 메인 채팅 작업과 앱 빌드 산출물을 건드리지 않도록 격리된 출력 폴더에서 검증했습니다. 서버 배포, 전체 네이티브 동기화, APK/IPA 패키징 및 실기기 설치는 수행하지 않았습니다. 다음 네이티브 동기화·빌드에 새 웹 로딩 화면이 포함됩니다.
