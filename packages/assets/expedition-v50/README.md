# 동물 구출 원정 전용 동물

내장 ImageGen으로 판다·사막여우·레서판다의 투명 배경 원화 시트와 공통 구출 포스터를 제작했습니다. 사막여우 시트는 기존 여우의 포즈 순서를 따라 새로 제작했고, 공통 포스터 속 동물도 같은 사막여우 모습으로 바꿨습니다.

- `source/{panda,fox,red-panda}.png`: 실제 출력 1254×1254, 4×4 셀, 알파 포함 원본. 이미지당 16포즈.
- `runtime/*.webp`: 256×256, 동일 동물 내 크기·발 기준선 정렬. 앞·뒷모습, 네 방향 보행, 하품·수면·기지개용 48프레임.
- `rescue-poster.webp`: 960×640, 루미가 세 친구를 정원으로 안내하는 공통 포스터.
- `animals-preview.webp`: 세 동물 정면 미리보기.
- `prompts.json`: 원문 프롬프트와 생성 방법.
- `sprite-report.json`: 알파 경계 추출·스케일·정렬 정보.

재생성: `node --import tsx tools/garden-world/build-expedition-animals.ts`

프레임 0~5는 서기·호기심·눈감기·하품·잠·기지개, 6~9는 앞면 걷기, 10은 뒷면 정지, 11~14는 뒷면 걷기, 15는 추가 뒷면 정지입니다. 렌더러는 앞·뒷면을 각각 좌우 반전해 네 방향을 표시합니다. WebP 품질 92, 알파 품질 100으로 저장해 새 런타임 이미지 전송량을 원본 PNG 추출본 대비 약 80% 줄였습니다. 원화의 색이나 동물 형태는 코드로 다시 그리지 않았습니다.
