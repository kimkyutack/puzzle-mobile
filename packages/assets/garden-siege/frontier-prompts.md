# Shelf, awning and expedition art

Mode: built-in imagegen, transparent background. Source sheets are preserved in source/ and runtime frames are generated by tools/asset-pipeline/garden-siege-build.mjs.

## Shared prompt

Use case: stylized-concept. Production raster art for an original premium mobile match-three garden game, polished painterly 3D toy illustration with chunky silhouettes, rich jade, warm ivory, coral and antique gold, soft upper-left highlights, clean readability at 40 pixels. ACTUAL TRANSPARENT ALPHA, no baked background, floor or shadow. No text, numerals, UI or watermark. Keep generous edge-safe framing yet fill each tile nearly edge to edge.
